# @deepseek-ai/dsh-product-insight-workflow

模型输出未完成时记录具体结束类型。某批语义审核失败仍会影响交付。缺少独立佐证只作披露，不再为此调用模型比对或补搜；原始来源资格检查仍保留。交付原因不重复列出同一未回答问题，跨站核对的一般局限保留在报告局限中。

[English](README.md) | 中文

页面发布方声明缺失或与登记名称不同，只在对应问题下提示，不排除来自已批准域名的证据。历史跨来源比较中的不确定或冲突同样只作披露；有原文支持的各方陈述仍可参与综合，并保留不同适用条件。原文支持、引用完整性、当前性、批准域名和明确范围检查继续保留。

## 概述

计划获批后，产品调查获取网页，逐篇生成连贯提要，对照同一页完整正文审核，再生成带引用的报告。会话检查点保存已完成审核的提要，供中断后续跑。

<a id="use-this-package"></a>
## 使用本包

报告按实际覆盖情况列出可继续调查的问题。单页审核失败会记入运行记录，其他可用材料继续参与写作。

通过 `latestApprovedProductPlan()` 从持久化 Session 事件读取最新的原生或 PTC 明确批准结果，再用 `productPlanFromApproval()` 重建准确身份与获批计划；解析本身不授予执行权限。结构化区块接受版本 1（逐站发布方白名单，历史计划继续生效）和版本 2（`focus` 必填，记录用户从固定词表确认的关注方向与自定义补充，站点只能作为用户点名的 `additionalSites`；版本 2 拒绝 `sourcePublishers`）。新计划允许最多 30 个候选网页，不填写总耗时与规范正文字符上限。历史计划中明确批准的额度继续生效。

<a id="understand-the-implementation"></a>
## 实现说明

<details>
<summary>展开实现说明</summary>

[逐篇提要与全文审核](src/page-summary.ts)使用同一快照的元数据和正文。审核覆盖全部段号，只为需修订的段落返回替换文字、原因与原文依据。一次修订可同时引用页首、表格及脚注。整段没有依据时可以删除。审核格式有误时可就同一份提要纠正一次，未完成审核的页不进入写作。

历史摘录检查点按原流程执行。[审批交接](src/approved-plan.ts)从会话事件识别明确批准并校验结构化区块；仅解析待审计划不会授予审批。[运行入口](src/index.ts)复核审批，发现候选网页，获取入选页，将完整正文按 1,499 个代码单元的重叠设置切成有界片段，在全文偏移处核对候选摘录，去除相邻片段重复提出的同一证据，并在每段结束后保存已接受证据的检查点再进入审核。传输失败或单次请求超时可等待 500 毫秒，对同一窗口重试一次。符合条件的模型输出失败可把窗口拆成两个更短且重叠的范围。每个窗口在获批耗时内只走一种恢复路径。取消会终止重试等待，并在原检查点位置记录已用耗时。成功的子片段保留证据；无法恢复的范围作为限制披露，剩余有效材料仍可交付。新调查按片段与获批问题的匹配程度安排每页的首轮提取。还没有核验摘录的问题优先轮到，未匹配的片段随后按原文顺序处理。版本 3 检查点记录未完成网页的派发顺序。版本 1 和 2 按原有片段布局和原文顺序续跑。[审核判定](src/claim-review.ts)要求每条摘录都有明确判断，只有 `supported` 才形成来源限定结论。失败的审核批次也可拆分一次；有效半批的判断和结论会保留，无法恢复的半批使交付降为草稿。原文支持审核后直接进入综合写作，不执行独立佐证调用或佐证补搜；恢复时仍可读取历史比对记录。[报告评估](src/report.ts)检查来源资格、引用有效、来源校验值及是否存在冲突或不确定比对。操作失败、检索受限、未回答问题和缺少独立佐证改为限制披露，不单独判为草稿。它呈现实际查询结果、候选及获取数量和截断情况，不把搜索摘要当作证据，也不暴露提供方错误原文。外部来源须符合用户批准的发布方域名及页面声明；计划明确要求的地区、版本和日期也须与页面声明相符，缺失值保持未知。有证据但未达标时保留带引用草稿。

[会话工具](src/session-tool.ts)保存模型线路、完整请求、响应和页面身份。检查点将已修订段落绑定到来源快照和内容哈希。用户要求续跑时核对保存的正文，并按完全相同的输入复用已完成的调用。来源已变化时，报告说明材料来自保存的快照。第 1 至 3 版检查点沿用摘录流程，第 4 版继续逐篇提要。

</details>

<a id="model-experience"></a>
## 模型体验

### 搜索链接识别

#### 模型看到什么

常规搜索解析失败时，当前会话模型读取有界的搜索页观察，通过 `product/search-recognize` 只选择页面上显示的链接编号。搜索摘要和选中的链接仅用于发现网页，不作为证据。

#### Token 影响

每个来源的识别请求最多使用 1,024 输出 token。发现失败或尚未保存检查点时可能重复识别；常规解析成功则无需识别请求。

#### KV Cache effect

识别使用当前模型路由的独立请求，不重放会话对话。

### 产品证据提取与写作

#### 模型看到什么

阅读模型接收页面标题、网址、已观察到的元数据、完整正文、范围及全部研究问题。独立审核请求逐段检查普通描述、归因、限定词及影响判断的遗漏。写作模型接收已修订的提要、可引用的网页编号及图片观察，原始正文和审核前的提要保存在会话中。

#### Token 影响

阅读和审核各发送一次完整正文。提要按材料决定篇幅，受所选模型容量约束。完整输入超过上下文时记录该页失败。[报告输出处理](src/insight-output.ts)每次写作只传一份提要集合，局部修复保留其他已通过章节，句末角标指向对应原网页。

#### KV Cache effect

最多同时处理三页，每个任务先读页再审核，任一页完成即可启动下一页。检查点按抓取顺序推进，续跑按模型配置、完整输入、阶段及请求序号复用已完成的响应。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- **进程内任务** — 启动工具调用结束后，只要所属 Agent 仍在运行，任务会继续执行。进程重启后活动任务消失，已保存的任务记录显示为中断。同一获批计划可经再次明确调用，从已提交的检查点续跑；未成功落盘的模型响应可能需要重新调用。自动续跑和独立进度页面尚未实现。
- **复核范围** — 续跑重新获取已选网址，但来源变化或获取失败时仍保留原保存快照、证据和审核；报告注明依据历史内容，不代表网页当前状态。明确取消仍会中断续跑。
- **来源限制** — 关注方向计划的来源资格不再取决于域名是否登记：官网以外的页面按原文支持审核与来源类型使用，不再自动添加未登记站点提示；缺少独立佐证也不再追加固定提示，综合阶段依据材料内容说明具体限制。历史计划的域名未批准、地区/版本/日期不匹配和正文快照不一致只作报告披露，不单独判草稿。发现阶段仍在获取前筛选候选。没有语义支持或不能对应保存快照的陈述不进入已确认正文；没有支持结论的报告明确保留未回答问题。完全没有证据仍阻止报告生成。

<a id="dev-note"></a>
### 开发备注

<details>
<summary>展开维护说明</summary>

调用方须持久记录运行事实和模型请求，以便恢复调查决策。

</details>

产品模式自行注册后台任务控制器，不挂载通用任务完成通知。新计划批准后，在计划轮次结束时自动启动；拒绝或关闭审核不启动。`run_product_investigation` 保留用于用户明确要求续跑，`cancel_product_investigation` 用于明确要求取消；工具完成后结束本轮，不要求模型重写报告。重启服务并新建产品会话即可验证新预设。历史报告仍可读取，历史未完成计划不会被静默重启。

历史摘录检查点适用以下行为。审核结果逐条接收，单条缺失或无效不丢弃同批有效结论，也不单独阻止交付；缺失记录在对应问题披露。审核可将证据关联到其他已批准问题，原始提取归属保留。综合模型在有依据的句子后给出证据标记，程序校验实际引用编号并生成编号脚注；聊天页面和 HTML 将其显示为可点击上标。旧报告的段尾引用不会自动重定位，需要重新生成。

获批会话入口将同一计划轮次中成功网页搜索的结构化结果传入候选发现，排除更早轮次、失败调用和计划提交后的结果。已有检查点保留原候选池，新启动的调查使用交接材料。模型自行书写的网址不视为已观察到的搜索结果。

历史摘录检查点适用以下行为。整页证据提取最多同时处理三页。任意一页完成后即可派发下一页，即使排序在前的网页尚未完成。结果与检查点仍按网页顺序保存。重试占用当前页的槽位。取消后停止新派发并等待在途请求结束。明确设有正文字符额度的历史计划仍按原片段顺序提取。重启时重新访问尚未提交的预取页；Session 适配器在存在匹配且完整的已保存模型结果时复用响应。

网页原图最多同时读取三张，任意一张读完即可继续。一次调查中，图片字节、格式、图注和上下文均相同的材料共用读图结果，每次出现仍保留自己的来源页。有图片材料时，每章明确选择仅引用，或指定原图及其所在正文段落。配图位置可单独修复，已通过的正文继续保留。可比的配置或实测数据优先使用带角标的表格。导出的 HTML 内嵌选中的原图，可离线查看。

起售价比较逐项注明配置、地区和币种。常规起售价和有来源依据的教育优惠起售价分列，金额保留对应出处，缺失的价格在原位置标明。
