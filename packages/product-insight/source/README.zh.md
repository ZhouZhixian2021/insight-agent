# @deepseek-ai/dsh-product-insight-source

[English](README.md) | 中文

## 概述

本包将获批的产品计划转换为带筛选理由的网页清单，获取入选网页并核对原文摘录。它对每个问题执行一次有上限的 DSH Web 搜索，可对未回答问题各补充一次获批搜索，合并重复网址，并在其他查询或获取失败时保留已完成的工作。调用方负责 Web 提供方选择和持久化。

产品预设在隔离的 Web 注册表中加载本包。`searchEngines` 默认包含 DuckDuckGo、Bing 和 Yahoo（英国入口），并行接收同一条获批查询，不需要 API Key、Docker 或 dsh-web-tools。结果按排名交错合并、移除跟踪参数、去重，合计最多保留 10 条链接。单源失败时保留其他来源结果并标记覆盖受限，全部失败才报错；各源状态写入搜索结果诊断。验证码和未知页面格式属于失败，不伪装成成功的空结果。`searchHttp1Only` 默认开启以兼容代理，其他 HTTP 消费方保留原有传输默认值。免费网页入口可能变化或限流；三个引擎不代表三个独立索引，也不代表完整覆盖。

正文获取先使用有界 HTTP；正文为空或依赖 JavaScript 时，使用匿名本机 Edge（其他系统默认 Chrome）渲染。浏览器请求沿用公开网址检查和代理策略。默认每个并行搜索来源的 HTTP 超时为 25 秒，浏览器超时 30 秒、最多 60 次请求、响应最多 500,000 字符。浏览器仅允许 GET，不支持登录、验证码、交互操作及部分动态网页。搜索摘要仅用于发现网页，不作为证据；模型和网络仍可能产生费用。

## 使用本包

`discoverCandidatePages()` 在抓取前筛选获批来源域名、合并重复网址并保留逐查询失败。单次搜索结果上限与最终候选数独立。`fetchProductPages()` 最多同时读取三个入选页面，先保存完整规范正文，再发布快照。计划未显式限制字符数时，清理后的 HTML 和 PDF 正文不再因 12000/48000 字符、16 MiB 或 200 页而被拒绝；历史显式字符额度仍生效。`splitProductPageText()` 保留用于历史固定窗口，新无字符额度计划由工作流按模型上下文容量处理。摘录与保存的全文核对，PDF 保留物理页码。传输资源保护仍可配置：默认响应 64 MiB、正文 16,777,216 字符；超出时记录失败，不静默截断后冒充完整。浏览器请求数和网络超时保护保留。

<a id="understand-the-implementation"></a>
## 实现说明

<details>
<summary>展开实现说明</summary>

计划批准补搜时，首轮待核对候选按补搜次数预留名额，但不超过获批页数。获批发布方的搜索信息若提及产品名称开头的拉丁字母品牌，即使计划使用较长的描述性名称，也可进入有上限的正文检查；抓取后仍须通过来源与摘录核验。

[公开入口](src/index.ts)逐次搜索，某个提供方调用失败不会清空其他已结算结果。发现流程先筛选返回结果，再依次为入选、待核对和排除三组分配候选名额。首轮在每组内按获批问题顺序轮转，并沿用各提供方返回的排名。达到候选页上限后，未接纳的新网址使对应查询标记为截断，已接纳的网址仍会关联所有匹配的问题。网址去重时移除片段和已知跟踪参数，保留可能影响页面内容的查询参数。缺口查询使用产品名称、原获批问题的关键词以及获批的版本和地区，针对入选且未获取失败的网页最少的获批域名，并只接纳该域名的结果。数量相同时优先尝试尚未查询的域名。候选池满时，补搜入选页可以替换未入选页，也可以将同一网址提升为入选。已入选页无需重复获取。获批官网的页面进入有上限的正文检查。其他页面在搜索信息提及产品时入选，域名符合获批发布方时带上该发布方名称。其余有效网页待核对。搜索摘要和生成式回答都不是证据。[网页处理](src/page-content.ts)拒绝不完整和不支持的正文，将规范化文本绑定 SHA-256 内容身份，在不改写全文偏移的前提下拆分长页，为首轮提取按获批问题排列片段，提取长度受限的 HTML 发布方、发布日期、更新日期、地区和版本声明，并对照已保存全文逐条核对候选摘录。缺失或格式错误的声明保持未知；重复出现的摘录需要准确位置。[获取处理](src/page-fetch.ts)在获批的候选页范围内同时获取最多三个入选网页，并按候选顺序保存正文、记录成功或失败的快照。取消后停止派发，等待已开始的获取结束后返回。获取流程用 PDF.js 解析具有文本层的完整 PDF，在规范化正文中保存分页位置。已核验摘录保留准确偏移和物理页码。PDF 明确声明的发布方、产品版本、地区和来源日期沿用 HTML 的核验规则。HTML 初次提取超过获批正文上限时，获取流程按文档顺序保留完整的文章或主体区域，去掉导航、隐藏元素和媒体控件。抓取器返回的 Markdown 文本超限时，去掉行内链接和图片的目标地址，保留可见文字。转换后的文本仍超限时，可对同一个获批网址再读取一次原始网页。只有正文符合上限才保存，摘录偏移在这份规范化正文中核验。仍然超限的页面获取失败；`sameProductPageFacts()` 对比重新获取的正文与页面声明，不把新的获取时间和快照 ID 视为内容变化。

</details>

<a id="model-experience"></a>
## 模型体验

搜索页面结构未知时，每个来源最多进行一次有界浏览器渲染。常规解析仍失败时，产品工作流使用当前会话模型，仅选择页面中实际存在的外部链接编号。验证页仍拒绝。恢复最多读取 `searchRecoveryCharacters` 个字符（默认 16,000）及 `searchRecoveryLinks` 个链接（默认 60）；结果只用于发现网页，目标网页仍需获取并核验证据。关闭 `browserEnabled` 同时关闭此恢复路径。

#### KV Cache effect

恢复将受限的页面观察交给工作流独立模型请求；普通解析成功时不增加模型调用，也不重放会话对话。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- **文档提取限制** — PDF 需要可提取的文本层，并同时受 16 MiB、200 个物理页和获批正文字符数的限制。HTML 规范化覆盖常见语义标签和实体；复杂的动态页面需要浏览器或 DOM 提取适配器。超过获批正文上限的页面会获取失败。若不启用重叠，跨片段边界的摘录可能遗漏；产品工作流为最长 1,500 字符的摘录重复 1,499 个字符的上下文。
- **编排由调用方负责** — 调用方保存正文与记录、提供候选摘录，并记录模型请求。消费方将异站认定为独立发布方前，必须另行核实发布方归属。本包不运行产品工作流或生成报告。
