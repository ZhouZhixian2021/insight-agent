# @deepseek-ai/dsh-client-ui-academic-research

[English](README.md) | 中文

已返回的报告在 Markdown 之外提供自包含 HTML 下载。HTML 复用现有 Markdown 渲染器，再经惰性允许列表序列化：内联样式、本地目录和证据链接，无脚本或外部资源。导出保留报告质量、限制、缺失证据及合成标记，不受页面搜索影响。Trace 面板按需查询真实 Session／运行诊断，支持阶段与状态筛选、记录分页及当前安全页下载。关闭页面只取消查看请求，不推测历史调用或排队耗时，也不自动轮询或启动研究。

HTML 阅读使用侧栏目录、适宜行宽的正文栏和可展开的依据列表。补充范围、逐题核对及证据索引置于正文之后，原始内容全部保留。交付未达标原因直接显示，内容限制提供带数量的展开入口。E1、E2 等证据简称链接到完整记录。排版不改写 Markdown、结论或质量判断。

## 概述

主 Web 侧栏在当前已保存会话中发起学术研究，分别展示正式 Remote 返回的运行状态、整轮处理结果、来源检索、全文获取、证据抽取、报告质量、覆盖统计、证据及 Markdown 下载。

候选选择期间，实时页面分别显示已完成的模型审核与审核计划数量、审核失败后的词项回退数量，以及未获模型审核而保留词项初筛的论文数量。这些数量与筛选阶段的去重论文总数分开。

## 使用本包

Q6 演示中的“运行生命周期预览”使用独立固定 JSON，区分查看连接与运行中、暂停、完成、受限完成、失败及取消状态。关闭、重开或切换预览记录保留本页记录及草稿；只有演示取消改变取消状态。漏斗上限不是通过数量，部分可用不等于正式纳入；未知数量与阶段耗时保持未知。草稿下载为 academic-demo-draft.md。预览不调用 Remote，仅在当前 Web 页面挂载期间保留。真实表单独立使用会话后台任务。

真实研究页面从 `watchBackgroundRun` 的完整快照读取 Q6 和最终结果，绑定会话、后台任务、检索运行及 Brief 身份，只接受递增的进度与 Q6 序号。逐题证据覆盖直接使用 supportingWorkIds、evidenceIds 和 gaps；候选匹配不能推导为证据支持，缺少 Q6 时不回退到样例。

侧栏另提供明确标注的“Q6 只读演示”，无需选择会话。它使用规范查询流程合成 JSON 的包内副本，回归测试检查两者完全一致。计划、候选和覆盖视图复用 Q1 类型；搜索与优先级筛选保留生产方队列顺序；快照选择显示记录的绝对计数，不替换单独评估的证据覆盖。样例缺少论文标题和作者，因此显示标识及缺项提示。该入口不调用 Remote 或模型，也不作为真实结果的回退。候选调整、审批操作及引用扩展等待负责人确认正式接口。

完整后台快照保留最多 20 条本次监听观察到的递增进度。六个阶段、并发论文、批次、尝试及证据数量均使用真实返回值。页面集中展示发现记录、去重论文、已选候选、可用全文、已验证证据、实际纳入论文和报告状态；这些数字单位不同，运行中仍会变化。未知值保持未知，耗时使用最新快照，不展示进度百分比或预计完成时间。断线保留已有观察，并提供显式重新读取与监听，不重新启动研究。

已批准计划预览区分直接搜索来源与引用核验来源，并展示渠道、问题及每条查询的预算。`hybridRetrieval` 是终态观察记录：页面直接展示五个阶段与不同单位的 URL、引用和论文数量，不推测实时进度。缺少投影或旧计划策略时明确说明未知。识别引用不等于核验成功。报告预览和 Markdown 下载原样保留标记为 `retrievalDisclosureIncluded: true` 的服务器 Markdown；其他报告使用同一实际结果附加带标题、经过转义的检索披露；不改变质量状态，Web 候选 URL 不进入参考文献。

草稿存在 `insufficient_coverage` 评测问题时，保留 Markdown 下载并显示本地化的证据有限提示。正式交付被阻止不会隐藏已有草稿。

运行面板将洞察状态和原因与抽取及审核分别展示。`partial_success` 保留草稿下载和被拒候选段落原因，不表示报告审核通过。逐题回答与缺口位于 Markdown。洞察失败或被阻止时不提供报告下载。

`renderResearchPage()` — 传入已评测的 ResearchReport 和明确的 zh-CN 或 en 界面语言。返回的 HTML 包含样式与交互，不依赖服务或外部资源，报告文字在 HTML 和嵌入 JSON 中均转义。搜索筛选结论和证据，证据链接展开详情，下载导出原始 Markdown。该渲染器继续作为内部辅助函数。主 Web 通过 sidebar.footer.action 注册研究入口，并使用框架 locale 字典。

批准研究计划后，页面通过 `academicResearch.plan` 预览当前计划，使用 `startBackgroundRun` 提交真实 Session、批准的 Brief 标识和 synthetic: false。打开页面时列出服务端保存的任务，优先读取运行中的任务，否则读取最新记录；用户可选择历史记录。关闭、切换会话及刷新只停止监听，重开时通过 getBackgroundRun 和 watchBackgroundRun 读取原任务及报告。只有 cancelBackgroundRun 发送取消命令。启动响应丢失时先重新读取记录，避免重复执行；当前批准缺失不阻止查看已有结果。服务中断不会自动恢复执行。

逐篇结果区分完整、部分与失败的抽取状态。页面显示合格证据数量、被拒草稿序号和本地化原因。草稿序号从一开始显示，来源片段序号保留为生产方诊断。被拒陈述不会作为合格报告证据展示。

一级草稿完成后，用户可选择一篇保留有效证据的已抽取论文版本，调用现有 `enhanceEvidence` Remote。同步点击锁及持久化 Session 选择记录防止重复触发；读取历史成功后才允许选择。页面通过既有 Session follow 快照和向前分页读取选择、结算及已核验增强片段，限定当前运行和版本。新增摘录与实际终态数量独立展示，原报告保持不变。增强失败或取消时，即使终态失败数量为零，也可以保留已提交摘录。缺少结算时显示未确认，不推断成功或自动重试；重新打开恢复持久事实。关闭此面板会取消增强 RPC，与独立后台研究不同。增强不重新生成、批准或替换草稿，不展示服务器进度百分比。

报告分别展示交付未达标原因，以及内容限制与未回答问题。缺少独立审核不单独阻止交付；ready 表示交付检查通过，不表示语义审核通过。客户端保留历史报告原状态，不自行重新标记。

<a id="model-experience"></a>
## 模型体验

### 返回结果

#### 模型看到的内容

独立渲染器 `renderResearchPage()` 仅返回数据，不发送模型请求。Web 表单向 Academic Controller 提交预览过的批准身份；工作流负责模型提示词和研究状态记录。

#### Token 影响

发起研究可能通过配置的工作流消耗模型 Token。查看、筛选和下载已有结果不发起额外模型请求。

#### KV Cache 影响

本包不操作模型缓存。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与后续工作

- 页面直接使用 AcademicBackgroundRunView 和 AcademicResearchRunValue，支持显式重连及服务端记录恢复，不提供自动重试、检查点续跑或 Brief 审批操作。监听断开不能证明服务器已取消；取消以服务器结算为准。用户内容以文本渲染；页面没有独立可分歧状态，因此不发布 invariant 入口。
