# 产品报告交付限制披露

[English](guide.md) | 中文

## 变更

产品报告不再将非空的失败操作列表、检索覆盖受限、未回答问题或缺少独立佐证单独判为草稿。这些事实仍在报告中披露。正式报告不代表覆盖完整或已经独立验证。引用无效、来源不合格或过期、缺少语义审核、取消和报告生成失败仍会检查。完全没有有效证据时仍不生成报告。

新调查同时取消独立佐证模型调用及专门的佐证补搜，保留未回答问题补查和原文支持审核。进度卡调整为四阶段，历史比对记录仍可查看。

页面发布方声明缺失或名称不同、历史跨来源比较的不确定或冲突仅作披露，不阻止交付。具有原文支持的内容继续参与报告综合，差异陈述保留各自条件与不确定性。

## 迁移

1. 重新构建并重启 Web 服务，再创建新调查。
2. 即使交付状态为正式报告，也要阅读逐题限制及检索取证范围说明。
3. 已保存报告保持历史状态，本次不会重写；可用新获批调查或明确的离线重放核对新规则。
