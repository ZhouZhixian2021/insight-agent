# 产品报告交付限制披露

[English](guide.md) | 中文

## 变更

产品报告不再将非空的失败操作列表、检索覆盖受限、未回答问题或缺少独立佐证单独判为草稿。这些事实仍在报告中披露。正式报告不代表覆盖完整或已经独立验证。引用身份无效、取消和报告生成失败仍会检查。完全没有有效证据时仍不生成报告。

新调查同时取消独立佐证模型调用及专门的佐证补搜，保留未回答问题补查和原文支持审核。进度卡调整为四阶段，历史比对记录仍可查看。

页面发布方声明缺失或名称不同、历史跨来源比较的不确定或冲突仅作披露，不阻止交付。具有原文支持的内容继续参与报告综合，差异陈述保留各自条件与不确定性。

来源资格、正文快照不一致、恢复时来源变化或复核失败，以及没有任何支持结论，不再单独阻止正式交付。适用范围不同的观察保留限制；快照无法对应或原文不支持的陈述只供核查，不作为已确认结论。续跑保留原保存快照并另行记录新观察，不再因实时网页变化丢弃已有证据。

## 迁移

1. 重新构建并重启 Web 服务，再创建新调查。
2. 即使交付状态为正式报告，也要阅读逐题限制及检索取证范围说明。
3. 已保存报告保持历史状态，本次不会重写；可用新获批调查或明确的离线重放核对新规则。

审核结果逐条接收，单条缺失或无效不丢弃同批有效结论，也不单独阻止交付；缺失记录在对应问题披露。审核可将证据关联到其他已批准问题，原始提取归属保留。综合模型在有依据的句子后给出证据标记，程序校验实际引用编号并生成编号脚注；聊天页面和 HTML 将其显示为可点击上标。旧报告的段尾引用不会自动重定位，需要重新生成。
