# 产品洞察在计划获批后搜索

[English](guide.md) | 中文

## 变更

内置产品洞察预设原先在计划阶段提供 `web_search` 和 `web_fetch`。新版从对话确认产品与关注方向。计划获批后，后台通过产品模式自己的 Web 服务收集、筛选网页，再分配阅读名额。新提交的关注方向计划需要为每个问题列出独立查询。

## 迁移

1. 如果自定义产品计划提示要求预搜，把该要求改为后台需要查证的问题。在新提交的版本 2 `product-insight-plan-json` 中，用 `searchQueries` 为每道题提供一组可单独搜索的短查询。已批准的计划继续使用当时记录的查询格式。
2. 重启本地 DSH 服务，新建产品洞察对话，输入产品及关注方向。系统先展示计划，批准后调查卡才开始显示网页发现进度。
