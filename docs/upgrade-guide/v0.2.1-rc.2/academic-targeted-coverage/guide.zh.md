# 定向学术覆盖

[English](guide.md) | 中文

## 变更

Controller 新运行按获批缺口选择论文和原文段落，最多补抽两篇已有论文，保留一次候选补读，并仅复核受影响方面。用户可见计划保留原问题。`coverageTargeting` 冻结字符、调用、token 和耗时上限。来源预览用于选择补抽内容，不能构成证据或证明覆盖。

定向补强状态在既有必需覆盖事件下使用 `schemaVersion: 2`。旧读取程序拒绝对该状态进行可执行恢复。新读取程序仅接受不含 targeting 的历史 schema-1 状态，并沿用其冻结算法；不会给历史运行重新授予定向额度。既有报告保持不变。

## 迁移

1. 启动定向运行前同步升级写入和可执行恢复程序。补强状态判别值可防止不安全恢复，因此 Session 头部版本保持不变。
2. 检查 Controller 的 `coverageTargeting` 默认值：6,000 字符原文、六次模型调用、45,000 个估算或预留 token、220 秒。恢复后保留持久化额度预留。token 估算不是精确的提供方硬上限；输出和时间故障保持显式可见。
3. 确认有限补强后未解决的问题仍为部分回答。检查已记录的首次及局部核查输入、原文定位和已核验摘录。见[工作流行为](../../../../packages/academic/workflow/README.zh.md)。
