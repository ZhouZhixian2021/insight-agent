# 产品调查容量

[English](guide.md) | 中文

## 变更

新产品计划最多支持 12 个候选网页、20 分钟总耗时，每页规范正文上限须获批且在 12,000 至 48,000 字之间；未写明时沿用 12,000 字默认值。未批准的外部域名会在抓取前排除，即使搜索标题包含产品名称。新版提取按问题选择已保存网页的原文位置，每页最多形成八条证据，单条证据可引用最多三段准确原文；模型容量与传输保护仍然生效。新模型审计记录携带计划身份，旧记录仍可读取，不推测关联关系。

## 迁移

1. 构建本地仓库后重启 Web 服务。
2. 新建并批准包含候选页、耗时和正文上限的产品计划。将所需外部发布方域名列入 `sourcePublishers`；批准官网不等于批准第三方评测站点。
3. 配置所选模型的输出容量和上下文信息。未披露的上下文由服务商校验，不猜测容量。
4. 运行后查看产品卡中的过程详情并下载 Trace。缺少计划身份的历史记录可能只有部分追踪条目。
