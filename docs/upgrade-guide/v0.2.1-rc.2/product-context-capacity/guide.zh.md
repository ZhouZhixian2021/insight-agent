# 产品调查容量

[English](guide.md) | 中文

## 变更

新产品计划最多支持 30 个候选网页，不填写总耗时和规范正文上限。已批准计划中明确写入的额度继续生效。未批准的外部域名会在抓取前排除，即使搜索标题包含产品名称。证据提取和报告综合不再限制固定摘录数量、字符数和字节数；模型配置容量与传输保护仍然生效。模型审计记录可选携带计划身份，旧记录仍可读取，不推测关联关系。

## 迁移

1. 构建本地仓库后重启 Web 服务。
2. 新建并批准产品计划以使用新默认值。将所需外部发布方域名列入 `sourcePublishers`；批准官网不等于批准第三方评测站点。
3. 配置所选模型的输出容量和上下文信息。未披露的上下文由服务商校验，不猜测容量。
4. 运行后查看产品卡中的过程详情并下载 Trace。缺少计划身份的历史记录可能只有部分追踪条目。
