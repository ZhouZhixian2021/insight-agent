# 产品调查容量

[English](guide.md) | 中文

## 变更

新产品计划最多支持 30 个候选网页，可不填写总耗时和每页规范正文字符上限；明确获批的额度仍须执行。未批准的外部域名会在抓取前排除，即使搜索标题包含产品名称。新版提取按问题选择已保存网页的原文位置，不再设置每页首轮固定证据数量上限，单条证据仍最多引用三段准确原文。提取输出遵循所选模型线路容量，不再受产品专属 token 或响应字节上限约束；传输保护仍然生效。新模型审计记录携带计划身份，旧记录仍可读取，不推测关联关系。

## 迁移

1. 构建本地仓库后重启 Web 服务。
2. 新建并批准包含候选页上限的产品计划；耗时和正文字符上限可省略。将所需外部发布方域名列入 `sourcePublishers`；批准官网不等于批准第三方评测站点。
3. 部署要求请求输出上限时，为所选模型配置该上限。未配置时，提取为上下文检查预留 8,192 token，实际输出仍由模型线路控制。未披露的上下文由服务商校验。
4. 运行后查看产品卡中的过程详情并下载 Trace。缺少计划身份的历史记录可能只有部分追踪条目。
