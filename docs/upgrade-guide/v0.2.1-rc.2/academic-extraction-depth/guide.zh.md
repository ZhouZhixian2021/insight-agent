# 学术证据抽取深度

[English](guide.md) | 中文

## 变更

正式学术研究运行默认使用 `extractionDepth: complete`，每篇五条记录上限仅适用于 `minimal` 模式。完整模式优先调度关联研究问题的原文范围，同时抽取发现、实验条件和局限。原有每篇调用次数和超时预算仍然生效，模型用量和耗时可能增加。排序批次还会评估证据是否回答全部要求，之后才将问题标记为已覆盖。

## 迁移

1. 保持默认值即可使用有预算的完整抽取。如需保留五条模式，在配置档或 home 补丁中现有 Academic Research Controller 条目的完整 `config` 值中设置 `extractionDepth: minimal`，同时保留其他配置。
2. 重启应用并新建研究运行，已有报告保持不变。完整模式下每篇可能贡献五条以上核验证据；未获回答的方面保持部分覆盖，并可触发后续批次或检索轮次。
