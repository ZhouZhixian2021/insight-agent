# 限制全文筛选开销并复用论文来源

[English](academic-fulltext-budget-cache.md) | 中文

## 概要

排序式学术研究先审核学术标题和摘要，再下载选中的论文。独立预算限制全文探索与片段模型调用。可丢弃的来源缓存避免每个任务重新下载、解析同一论文；每个任务仍独立判断研究范围并抽取经过来源核验的证据。

<a id="admission-and-budgets"></a>
## 准入与预算

工作流发现并去重记录，应用获批硬约束，对候选排序，再分批审核有数量限制的标题摘要。Q5 优先准入已审核相关候选，然后才考虑不确定候选。未审核、相关性未知和审核失败共享探索额度。额度用完后，候选保留在候审名单，可在下一次下载或缺口检索前接受更多元数据审核，不会被归为不相关。预印本资格仍遵循获批 Brief。

| Controller 配置 | 默认值 | 计数方式 |
|---|---:|---|
| `candidateReviewMaximumWorks` | 24 | 所有轮次实际派发的元数据审核，失败也计入。 |
| `maximumFulltextWorks` | 24 | 本轮调度的不同论文版本，失败和缓存命中也计入。 |
| `maximumUncertainFulltextWorks` | 10 | 准入探索的未审核、未知或审核失败论文，包含在上述总额内。 |
| `scopeReviewMaximumBatches` | 3 | 每篇独立的范围审核批次。 |
| `extractionMaximumCallsPerPaper` | 8 | 每篇证据片段生成器尝试，包含重试和输入被拒的尝试。 |

全文限制不扩大已批准的候选或纳入上限。部署预算低于获批目标时产生明确限制说明。工作流保留目标及获批的证据不足策略。不确定探索为零时，必须先通过元数据相关性审核。片段阅读复用已批准的问题别名和现有词项优先排序；命中只决定阅读顺序。词项未命中或没有抽到事实，既不证明不相关，也不证明论文没有相应发现。一级证据五条上限在本次改动中保持不变。

<a id="source-reuse"></a>
## 来源复用

随 Web 提供的组合将 `fulltextCacheDirectory` 设置在 DSH home 的 `cache/academic-fulltext` 下。其他组合需要提供目录才能开启缓存。缓存保存原始 HTML/PDF、解析文本、来源哈希及段落／页码定位。键包含来源记录、学术版本类型与标签、标识符、Provider 和候选 URL；生成的任务身份和研究问题不参与键。命中后将来源绑定到当前任务身份、问题与抽取设置，保留实际获取时刻。

| 缓存配置 | 默认值 |
|---|---:|
| `fulltextCacheMaximumAgeMs` | 86,400,000 毫秒 |
| `fulltextCacheMaximumBytes` | 268,435,456 字节 |
| `fulltextCacheMaximumEntryBytes` | 33,554,432 字节 |

每条序列化记录包含原始与解析数据的校验和。解析器代际不匹配时，从原始文件重建解析文本。解析行为或定位语义改变时，维护者必须修改 `fulltext-cache.ts` 中的解析器代际。过期、原始数据损坏、版本改变或已知来源哈希不一致会触发重新获取。解析校验和损坏时可以重解析有效的原始文件。写入以原子替换完成，并按最早写入顺序删除记录，直到保留总量满足字节限制。超大记录正常处理但不缓存。同一 URL 的来源更新会在缓存过期后体现；新鲜度有时间上限，不持续重新验证。

只有来源材料可复用。每个 Brief 重新计算候选相关性、纳入、问题覆盖、证据 ID 和报告结论。首次未命中仍需下载并解析完整来源，包括完整 PDF；片段预算减少的是模型阅读量，不是首次下载。不引入向量数据库。草稿后的二级增强也使用同一缓存，并继续要求原证据哈希匹配。

<a id="failures-and-recovery"></a>
## 失败与恢复

失败、截断及不支持的正文不进入缓存。缓存记录无效或磁盘失败会发出警告，随后重新获取来源，或继续保留已经获取的有效来源。取消检查停止依赖工作。每次模型派发继续通过现有 Session 持久日志，缓存原文不绕过逐字引文核验。

检查点可选保存 `policy.fulltext`。新运行根据已保存的调度身份和元数据评估还原已用全文及探索名额。未结算批次保留原有调度计数，已完成批次不重新调度。历史检查点缺少该策略时，保持原调度解释。片段调用限制作用于每次单篇执行；被中断的论文抽取仍按既有恢复行为重试。清空可丢弃缓存不会改变 Session 证据或已批准研究要求。

<a id="verification"></a>
## 验证

定向案例覆盖相关候选优先、零探索、全文预算耗尽、候审继续审核、跨任务身份绑定、解析器失效、过期、损坏、取消及磁盘字节限制。现有当前策略 SDK Session 夹具在无网络下记录来源复用。这些确定性检查测量请求次数与保留数据，不测量真实模型延迟或文献召回率。

## 开发备注

默认预算是有限的运行默认值，不是最优研究质量的测量结果。应按预期纳入目标和来源长度校准。证据深度扩展仍是后续独立工作。
