# 学术洞察代码导航

[返回学术洞察目录](00-目录.md) · [模块分工](模块分工/00-目录.md) · [整体与分块架构图](架构图/00-目录.md)

本页用于回答“某项功能的代码在哪里、负责什么、先读哪个文件”。路径按当前本地源码核对，日期为 2026-11-04；文中代码路径均相对 `insight-agent` 仓库根目录。学术业务、后台、页面和业务装配位于 `packages/academic` 下，共 19 个代码包；运行仍依赖目录外的应用装配、公共框架和构建接入。

目录分工见[代码组织与复用说明](02-代码组织与复用.md)；复制源码、迁移目录或合并上游时，统一使用[学术洞察接入与迁移清单](上游合并/学术洞察接入与迁移清单.md)，本页不另维护运行接入清单。领域勘察代码已通过 PR #134 合入 master；合入状态不等于真实运行验收，本轮资料整理未执行真实论文检索或模型研究。

## 先从哪里读

第一次了解项目，建议按以下顺序阅读：

1. [学术模式配置](../../packages/academic/bundle/presets/academic.patch.yml)：了解模式如何启用、计划如何提出以及技能从哪里加载。
2. [页面入口 ResearchEntry.tsx](../../packages/academic/ui-research/src/client/ResearchEntry.tsx) 和 [后端 Controller](../../packages/academic/research-controller/src/index.ts)：了解用户操作如何进入后台。
3. [工作流入口 entry.ts](../../packages/academic/workflow/src/entry.ts) → [模型适配 model-pipeline.ts](../../packages/academic/workflow/src/model-pipeline.ts) → [主流程 pipeline.ts](../../packages/academic/workflow/src/pipeline.ts)：了解一次研究如何组织检索、处理论文、补充证据和生成报告。
4. 按具体需求深入下方的检索、证据、分析、报告或页面模块；共享数据定义先看 [model](../../packages/academic/model/src/index.ts)。

`.ts`、`.tsx` 和配置文件是修改入口；`lib/`、`lib/types/` 及构建生成的接口文件不是优先编辑对象。各包的 `src/index.ts` 通常是对外导出入口，具体实现往往在同目录的其他文件中。
