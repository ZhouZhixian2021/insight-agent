## 补登范围与维护责任

原有 20 个漏登路径已逐项核对差异：17 项是人工改写，3 项是翻译配对生成记录。人工改写涉及 Python SDK 冻结部署、产品标识保留规则、计划投影恢复、学术快照身份替换、组合包测试定位和大仓库链接检查。它们不是此次新增的 20 个业务改动，补登记也不表示这些行为已重新验收。

新增登记的升级维护入口按[现有成员 A 的合并上游与兼容集成职责](../模块分工/academic-upstream-upgrade-dual-route-team-plan.md#成员工作范围)归口 `ZhouZhixian2021`。`owner` 表示该项升级维护的联系入口，原始实现作者及审查记录由 Git 历史保留。

三项配对记录分别属于单文件 SDK 运行时架构说明、重命名规则说明和 Python SDK 运行时说明，已同时补入生成物映射。复核另补齐已有模式文案 README 配对记录的重建命令；43 项已登记生成物均有映射，原有公共 Remotes 配对重放入口继续保留，共 44 个重放输出。新增项的分类依据实际差异：文档正文、测试及行为实现归为 `fork`，可完整重建的配对记录归为 `generated`。
