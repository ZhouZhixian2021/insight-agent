# 学术洞察接入与迁移清单

[返回上游合并资料](00-目录.md) · [代码导航](../01-代码导航.md) · [代码组织与复用](../02-代码组织与复用.md)

本页是学术洞察运行接入与迁移处理的唯一维护页，用于复用源码、调整目录和合并上游时核对必须一起保留的连接。路径相对仓库根目录，按 2026-11-04 源码整理；其他导航页只保留摘要和本页链接。文件级差异及负责人仍由 [scripts/upgrade](../../../scripts/upgrade/README.zh.md)中的正式登记表维护，本页不复制其统计数；本轮登记处理见[登记补齐结果](2026-11-04-登记补齐结果.md)。

本页区分业务源码、公共框架、应用装配、生成物和历史兼容材料。领域勘察代码已通过 PR #134 合入 master；本页依据源码接入关系整理，实际检查结果见[本轮核对记录](2026-11-04-登记补齐结果.md)，不能将接入关系视为真实研究验收结论，也不承诺合并上游没有冲突。

## 3. 迁移与验收的处理边界

业务包连同资源迁移；公共扩展点保留在框架所属层；应用 manifest/profile 保留加载策略；别名、项目引用和检查范围随路径更新；生成物从合并后的声明重建；历史格式和验收材料保留原义。每类都有不同消费者，不能用一次文本替换或一份文件登记表代替这些核对。

业务验收对照 [T0 基线](验收基线/t0-feature-checklist.md)及后续[开发记录](../开发记录/00-目录.md)，实际运行结果另行记录。尚未执行的真实来源访问、模型调用、恢复和交付场景应保留未验收状态。

## 4. 历史旧工具的保留边界

[历史方案](历史方案/00-目录.md)和其中的 upgrade-kit 保留原始交付及登记背景，现行可执行工具在 scripts/upgrade。只读文件摘要比较显示，历史 `replay-generated.mjs` 与对应现行脚本内容相同，历史 `verify-upstream-overrides.mjs` 与现行脚本不同；旧 JSON 属于当时的登记与生成物映射快照，不能作为当前状态。

内容相同不足以证明历史副本可以删除：历史导航、方案和安装原稿仍说明整个工具包的交付背景。当前保留这些材料，不执行历史脚本，也不用旧 JSON 覆盖正式登记。以后若要去掉重复可执行文件，应先明确如何保存交付快照并处理历史引用；差异文件不能按“重复副本”清除。本轮不删除历史文件，不改写历史开发记录或登记核对原始证据。
