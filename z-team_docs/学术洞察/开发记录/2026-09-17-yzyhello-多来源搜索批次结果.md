## 目标

按 A 固定的交接规则与样例（`b-multi-source-search-batch.sample.json`）改造 `searchAll()`：单个 Provider 失败时保留其他来源的成功结果，并返回实际调用的 Provider、上限前发现记录数、`BatchResult<AcademicSourceWork>`、截断状态和来源覆盖限制；不修改 Academic 工作流、Controller 和 Web 页面。

## 完成内容

- `AcademicSourceSearchBatchResult` 继承 `AcademicSourceSearchResult`：新增 `providers`、`discoveredRecords`、`batch`、`limitations`，继承的 `works` 镜像 `batch.items`，未改动的 Controller 转发与工作流适配器无需变更即可编译运行。
- `searchAll()` 等待全部可用 Provider：被拒绝的 `AcademicSourceError` 转换为不含凭据、可重试的 `upstream_error` 级 `ProviderFailure`（非预期拒绝值为 `unknown` 且不可重试），成功结果与失败明细交给共享 `createBatchResult`，零结果成功为 `success`、两者并存为 `partial_success`、全部失败为 `failed`。
- 取消整轮以 `ACADEMIC_SOURCE_ABORTED` 中止（重抛提供方中止错误，或信号已中止时合成），不编造 ProviderFailure；无可用 Provider 等配置错误继续抛出原错误码。
- `discoveredRecords` 按应用聚合 `maxResults` 上限前各 Provider 返回数统计；seam 不再按 Provider 预截断（与固定样例的 5>2 口径一致）；`truncated` 覆盖提供方与聚合两层丢弃；聚合上限丢记录时生成一条限制说明。
- `AcademicSourceProvider` 增加可选 `limitations` 声明字段；CVF、ACL Anthology、PMLR 声明仅覆盖配置目录，arXiv 不声明（与样例一致）。
- 同步更新 source 与三个 Provider 包的 README（双语）、`docs/subsystems/academic-source` 页（双语）、API 目录（`gen-cordis-catalog` 重新生成）与 Agent Note 三件套。
