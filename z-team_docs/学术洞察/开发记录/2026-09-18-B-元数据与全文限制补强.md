# B：元数据与全文限制补强

本轮按用户要求停止扩展联网测试，仅修改 B 的 OpenAlex 规范化和来源服务，保留 `searchAll()` 的入参、返回类型及 A/C 接线不变，未编辑 note 文件夹。

- 首次公开日期：OpenAlex 的聚合日期仍不冒充首次公开日期。新增从合法 arXiv 详情/HTML/PDF 链接提取成果级标识符，使已检索到的 OpenAlex 与 arXiv 记录可经现有摄取流程合并，采用 arXiv 的首次公开日期。没有权威记录时仍为未知，不自动补查，不硬编码代表作。
- 会议出处：仅从发表版本的位置记录提取发表场所，不把 arXiv 等 repository 的托管名称当成会议。未提供场所则为未知；没有新增“顶会”排名判断。
- 论文版本：相关预印本的标识符只用于成果级关联，不混入正式发表版本的标识符或全文地址；明确记录 OpenAlex 的版本类别不能确定精确修订号。
- 缺失说明：已有 `limitations` 返回保留结果中首次公开日期、场所、版本类型未知的数量，以及无全文候选或候选解析异常的数量。搜索仍可成功；限制不伪装成已发生的下载失败，也不把“暂无地址”说成“没有全文”。

本地回归覆盖：BERT 的正式版本与 arXiv 预印本合并成一篇成果、保留两个版本、首次公开日期为 2018-10-11；仓储名称不冒充会议；元数据/全文候选缺失及解析异常不丢弃搜索结果。来源、OpenAlex 和摄取范围共 58 项测试通过。没有重新执行联网测试或模型调用。

边界：这是已经取得的元数据的关联与可信表达，不是自动权威元数据补查系统。若搜索只返回 OpenAlex，且没有取得对应 arXiv 等权威记录，首次公开日期仍不能自动补齐。此前发现的 arXiv `truncated` 标记问题不属于本次优先修改范围，仍待修复。
