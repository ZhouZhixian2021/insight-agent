## 目标

完成混合检索计划 A-H2：让普通用户审核可读中文研究意图和来源预算，同时由系统在同一次批准记录中保存每条查询的渠道、直接检索 Provider、引用核验 Provider、Web 发现上限和核验上限；不让用户填写枚举或 JSON，也不在 A-H3 完成前静默忽略获批策略。

## 实际完成

- 将新计划交接升级为 schema version 3，每条 `searchPlan` 项要求 `query`、中文 `purpose`、关联 `questions` 与 `retrieval` 策略。
- 第一版直接检索只允许 OpenAlex、arXiv；引用核验允许 OpenAlex、arXiv、ACL、PMLR、CVF。
- Web 发现与引用核验的产品上限均固定为 8；模板默认每条查询最多发现 8 个 Web 结果、核验 5 条引用。
- 校验未知、空、重复或不支持的渠道/Provider，未知字段，负数、超限与依赖渠道不一致的 Provider/预算组合。
- 完全相同的查询只有在检索策略一致时才能合并；策略不同则要求修正并重新审核。
- 计划模板在可读中文部分说明渠道、来源和预算；系统执行块由系统填写，用户无需理解技术字段。
- 第 1、2 版计划继续读取和执行原有路径。第 3 版计划可以预览，但 A-H3 完成前运行会返回明确提示，防止旧工作流忽略已批准策略。
- 更新 Controller 双语说明、计划架构决策、A-H1 共享接口决策与团队计划状态。
