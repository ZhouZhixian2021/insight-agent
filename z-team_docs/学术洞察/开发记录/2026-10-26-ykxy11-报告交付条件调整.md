# 报告交付条件调整

本轮取消独立语义审核记录、单篇陈述审核及逐题内容审核作为正式交付前置条件。工作流使用 auto，由其余检查自动选择报告或草稿；不伪造审核记录，不增加模型调用。

引用、版本、定位、哈希、证据准入、等级、支持论文与全文最低数量、跨论文独立支持、计划批准、置信度、冲突披露、必要结构和非合成数据要求保留。已提供但无效或不支持结论的审核仍阻止交付。逐题关联、模型回答状态及内容缺口作为内容限制展示，不单独阻止交付。

主页面、Markdown 和 HTML 导出分别展示交付未达标原因及内容限制与未回答问题。历史 Session 报告不重写，新研究才使用新规则。

本地构建通过；工作流、报告和评测定向测试 186 项通过；页面、HTML 导出及交付场景测试 30 项通过，数字有重叠，不累计。未发起外部模型研究，真实效果由用户本地验收。初始按用户要求仅保留本地，之后用户要求提交并推送，PR 由用户创建。

两项无密钥 SDK 场景复验通过（筛选命令共 3 项通过）。定向源码静态检查及文档格式检查通过。全局页面国际化检查有 7 项已有问题，经逐文件比较本轮前后数量一致：HTML 导出模板 1 项、计划审批组件 6 项。

按用户后续要求取消全部报告字数门槛；既有计划上下限不再阻止交付，新计划填写空上下限。分析提示不按字数凑写或截断。字数政策相关 87 项定向测试通过。本轮未修改检索上限或来源配置。

推送前文档检查 32 项直接通过；报告问题分类导致 Cordis API 目录过期，使用仓库生成器同步该产物，再单项复验。
