# 证据—研究问题—结构化缺口接口补齐

日期：2026-10-09
负责人：成员 A（zhouzhixian2021）

## 问题

Q5 已有逐题覆盖结构，但正式运行曾把候选评估中的 `matchedQuestions` 当作证据支持关系，导致同一论文的全部证据被分配给该候选匹配的每个问题。候选相关性只能决定调度顺序，不能证明某段已核验引文回答了某个研究问题。

## 本次完成

- 在证据草稿中增加 `questionIndexes`，由模型用从零开始的序号声明同一引文直接支持的关注问题。
- 在抽取结果中增加运行期 `EvidenceQuestionLink`，把合格证据 ID 映射到输入中的批准问题原文；不修改可复用、可持久化的 `EvidenceRecord`。
- 对问题序号执行非负整数、去重和范围校验；无效关联只拒绝对应草稿，保留同篇论文的其他合格证据。
- Q5 覆盖只统计存在有效 `EvidenceQuestionLink` 的证据和独立论文，不再使用候选级 `matchedQuestions` 代替证据支持。
- 未覆盖和部分覆盖的问题继续使用既有 `gaps: string[]` 契约，写入明确缺口原因，保持 B 的补检查询与 C 的 Q6 投影兼容。
- 增加双问题回归验收：两个候选都在排序阶段匹配两个问题，但每条证据只计入自己显式关联的问题。

## 验证

- Evidence、模型响应解析和 Q5 补选聚焦测试通过。
- 全仓类型检查通过。

## 边界

- 本次不把研究问题写入持久化 `EvidenceRecord`，避免同一证据绑定某一版 Brief。
- 本次不修改候选排序、Q6 页面字段或补检查询返回类型。
