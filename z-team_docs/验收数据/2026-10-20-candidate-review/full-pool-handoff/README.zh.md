# 完整保留候选池交接

[English](README.md) | 中文

## 用途与范围

B/C 可以查看全部 276 篇保留的去重论文、追溯历史派发，并在没有模型、Web 服务或本机 Session 目录的情况下重放当前选择器。先看[可读候选清单](candidates.md)，再用[逐篇核对记录](audit.json)查询规范身份、筛选原因、分数、路由和请求序号。

来源为 2026-10-19 的智能体发展趋势研究，会话为 `session-aad43ed3-e716-4a7e-a300-61a8351b6cfe`。规范元数据、论文身份及 Plan 与已有[八篇评分交接包](../scoring-handoff/README.zh.md)一致。规范版本摘要和关键词来自保存的检查点，不使用 Web 摘要或其他版本的文本。

## 数量与含义

| 观察或离线结果 | 数量 | 含义 |
| --- | --- | --- |
| 历史发现记录数 | 463 | 保存的汇总计数；不包含逐条原始响应。 |
| 保留的去重论文／版本 | 276／286 | 全部保留的论文与版本身份均已保存。 |
| 学术摘要可用／未知 | 271／5 | 缺失摘要保持未知。 |
| 离线硬排除 | 30 | 每篇保留具体排除原因。 |
| 离线全文地址不可解析 | 23 | 地址解析不能证明 PDF 下载是否成功。 |
| 通过硬筛选及地址检查的候选 | 223 | 八篇送审，215 篇因审核预算未选。 |
| 历史实际请求／有效结果 | 8／3 | 2026-10-19 的旧审核调用，与后续 Pro／Flash 八篇复验分开记录。 |

历史审核后队列为 P0=0、P1=1、P2=13、excluded=262；当前代码重建的审前词项队列为 P0=0、P1=0、P2=14、excluded=262。队列排除也包含低于 P2 分数阈值的论文，因此 262 不是硬排除数量。选择器仍可审核硬筛选合格但分数低于队列阈值的论文；“未送审”不代表语义偏题。

在预算八篇、此前无尝试的条件下，当前选择器选中的八个规范论文 ID 与历史实际请求相同，顺序不同。前三个选择覆盖全部五个路由问题；各问题路由送审数为 4／6／3／2／3。这是路由覆盖，不是证据支持，也不能证明未选论文不相关。本池没有出现论文替换，不能宣称选取成员得到改善。

## 重放方法

安装仓库依赖后，在仓库根目录执行：

```powershell
pnpm exec vitest run packages/api/academic-research-controller/tests/candidate-pool-handoff.spec.ts
```

三个定向校验分别核对身份／元数据及与八篇包的对应、重放评估／排序及每条选择决定、核对真实派发与离线选择。入口只读共享文件并调用生产纯函数，不搜索、不下载、不请求模型，也不占用 Session 写入句柄。

## 限制与分工

“完整”指全部保留的去重池，不是全部 463 条原始发现响应或全部文献。Provider 截断、原响应逐条去重过程及十个非规范版本的元数据，不能从本包恢复。具体 URL 保留了 14 篇处理候选；其他“可解析”标记是历史地址事实，本包未提供其可下载文件。

- **B**：核对全池选择和队列决定，包括预算未选论文。保留批准权重与阈值；分数归因沿用已有八篇评分复核。
- **C**：独立标注相关性与可能遗漏，优先核对三篇 Pro／Flash 分歧；查看缺摘要、表面词项命中和硬排除论文。引文存在或路由覆盖都不是质量标准答案。
- **A**：提供可追溯输入，并处理已确认的提示词／调用／Session 接线问题。B 已合并的评分复核没有指出算法缺陷；本次导出未改变生产行为，也未增加模型调用。

[团队方案](../../../模块分工/academic-candidate-semantic-review-optimization-team-plan.md)分别跟踪独立质量、逐篇页面状态、报告下游核查及最终联合验收；本交接不宣称遗漏检查或端到端质量通过。
