# 产品洞察资料目录

[返回团队共享资料库](../00-共享资料导航.md)

本目录用于产品洞察开发的团队资料。代码位置与各目录职责见[代码目录规划](01-代码目录规划.md)，A、C 的职责与交接见[模块分工](模块分工/00-模块分工.md)，首版字段见[共享字段方案](接口约定/00-首版共享字段方案.md)，A 的网页发现接口见[候选网页发现与初筛接口草案](接口约定/01-候选网页发现与初筛接口草案.md)。`model/` 已建立共享记录，`source/` 已能获取网页和核对摘录，`workflow/` 已能从获批计划生成带来源的证据草稿，`bundle/` 已增加可选择的产品模式；控制器、报告和页面三个代码目录仍是占位，审批尚未接入自动运行器。

[证据抽取改造方案](证据抽取改造方案.md)记录按问题寻找原文、由程序摘录并结合上下文审核的待实施方案，以及迁移和验收要求。

已建立[架构图](架构图/00-目录.md)目录，后续保存整体及分块设计。按实际需要再建立“开发记录”“interface-samples”“验收数据”等子目录，保存开发记录、共享样例和验收材料。

团队通用规则见 [Git 协作规范](../01-Git协作规范.md) 和 [成员与分支](../02-成员与分支.md)。参考已有业务时，可链接 [学术洞察资料](../学术洞察/00-目录.md)，不要将其历史成果视为产品洞察已完成的工作。
