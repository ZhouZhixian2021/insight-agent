# 产品洞察资料目录

[返回团队共享资料库](../00-共享资料导航.md)

本目录用于后续产品洞察开发的团队资料。本次仅建立资料入口，尚未在这里登记具体开发计划、成员分工或验收成果。

后续按实际需要建立“模块分工”“开发记录”“架构图”“interface-samples”“验收数据”等子目录，分别保存职责与接口、实际开发记录、整体及分块设计、共享样例和验收材料。

团队通用规则见 [Git 协作规范](../01-Git协作规范.md) 和 [成员与分支](../02-成员与分支.md)。参考已有业务时，可链接 [学术洞察资料](../学术洞察/00-目录.md)，不要将其历史成果视为产品洞察已完成的工作。
