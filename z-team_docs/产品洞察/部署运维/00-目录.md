## 使用前提

新成员拉取的是仓库代码，**不包含运行时配置与会话数据**。`.dsh-runtime/` 与 `.env` 都被 git 忽略，必须按[部署说明](01-部署说明.md)自行准备。

## 共享边界

| 可以共享 | 不共享 |
|---|---|
| `.dsh-runtime/profiles/web/package.json` | `.dsh-runtime/sessions/` |
| `.dsh-runtime/profiles/web/cordis.patch.yml` | `.dsh-runtime/storages/` |
| [模板](模板/) 下的示例 | `.dsh-runtime/diagnostics/` |
| | `.env` 中的真实密钥 |

会话历史是个人数据，体积也在持续增长（一个月约 1 GB）。拷给别人既无必要，也会泄露调查内容。
