# 部署说明

[返回部署运维目录](00-目录.md)

从零开始到跑通一轮产品洞察。Windows 与 macOS/Linux 的差异单独标注。

## 一、环境要求

| 依赖 | 版本 | 检查命令 |
|---|---|---|
| Node | `^22.19.0` 或 `>=24.0.0` | `node -v` |
| pnpm | `11.28.5`（仓库已锁定） | `pnpm -v` |

```powershell
corepack enable
corepack prepare pnpm@11.28.5 --activate
```

## 二、拉取与安装

```powershell
git clone https://github.com/ZhouZhixian2021/insight-agent.git <仓库路径>
cd <仓库路径>
pnpm install
```

`pnpm install` 会从 GitHub 拉取 `dsh-web-tools` 这个 bundle。**网络受限时这一步会失败**，表现为安装报错或装完后搜索工具异常。

## 三、准备运行时配置

在仓库内创建运行时目录：

```powershell
New-Item -ItemType Directory -Force .dsh-runtime\profiles\web | Out-Null
```

放入两个文件，内容见[模板](模板/)：

| 目标文件 | 来源 |
|---|---|
| `.dsh-runtime/profiles/web/package.json` | [模板/package.json](模板/package.json) |
| `.dsh-runtime/profiles/web/cordis.patch.yml` | [模板/cordis.patch.yml](模板/cordis.patch.yml) |

`cordis.patch.yml` 里有两个值必须按本机情况修改，详见[配置参考](03-配置参考.md)：

- `apiKeyEnv`：密钥用哪个环境变量名
- `baseURL`：模型网关地址

## 四、设置 API key

任选一种，不要提交到仓库：

```powershell
# 方式一：当前终端
$env:WOWEI_GATE_API_KEY = '你的key'

# 方式二：仓库根 .env（已被 git 忽略）
'WOWEI_GATE_API_KEY=你的key' | Out-File -Encoding utf8 .env
```

## 五、构建

**必须执行。** 仓库的启动入口指向 `apps/cli/lib/bin.js`，该文件由构建生成。

```powershell
pnpm run build:artifacts
```

耗时约 2–4 分钟，结束时打印 `run-gates: 7 passed, 0 failed`。

改动 `packages/**/src` 后需要重新构建；只改 YAML 配置或提示词技能文件不需要。

## 六、启动

**方式 A：脚本启动（推荐）**

使用[模板/start-dev.ps1](模板/start-dev.ps1)，把文件里的两个路径改成自己的：

```powershell
.\start-dev.ps1
```

**方式 B：手动启动**

```powershell
$env:DSH_HOME = '<仓库路径>\.dsh-runtime'
$env:TEMP = 'D:\tmp'          # Windows 必须，且要在工作区之外
Set-Location <工作区路径>
node <仓库路径>\apps\cli\lib\bin.js web --port 54512
```

macOS / Linux：

```bash
export DSH_HOME="$PWD/.dsh-runtime"
cd <工作区路径>
node <仓库路径>/apps/cli/lib/bin.js web --port 54512
```

启动成功后终端打印：

```
dsh web: http://127.0.0.1:54512/?token=xxxxx
```

**必须用带 token 的完整地址打开**，直接访问端口会被拒绝。

## 七、确认装好

浏览器打开后，模式下拉框里应能看到「产品洞察」。

- 看不到 → 查[故障对照表](02-故障对照表.md)第一条
- 看得到 → 用它跑一轮，按下面的健康指标判断是否正常

## 八、健康指标

一轮正常的产品洞察应在这些区间内：

| 指标 | 正常范围 |
|---|---|
| 结算状态 | `final`（正式报告） |
| 证据条数 | 80 – 160 |
| 可读页面占比 | ≥ 70% |
| 耗时 | 默认推理档约 8 分钟；`max` 档约 20–30 分钟 |

明显偏离时先看[故障对照表](02-故障对照表.md)，两份数据对照着查。

## 九、已知红灯

`pnpm run check:ci:static` 在 master 上会有若干失败（客户端文案国际化、持久化目录同步等），属于仓库既有欠账，与本机环境无关。**不要试图修复它们来“让门禁变绿”。**

## 十、数据与磁盘

| 目录 | 内容 | 是否可删 |
|---|---|---|
| `.dsh-runtime/profiles/` | 配置，需要备份 | 否 |
| `.dsh-runtime/sessions/` | 会话历史，一个月约 370 MB | 可删，只影响历史回看 |
| `.dsh-runtime/storages/` | 会话索引与缓存 | 可删，会重建 |
| `.dsh-runtime/diagnostics/` | 排查日志 | 可删 |

这些目录都不进 git，也不要在成员之间拷贝。
