# 配置参考

[返回部署运维目录](00-目录.md)

运行时配置都在 `.dsh-runtime/profiles/web/`，两个文件各管一件事。

| 文件 | 管什么 |
|---|---|
| `package.json` | 这个 profile 装了哪些 bundle |
| `cordis.patch.yml` | 每个插件实例的配置：模型、密钥来源、界面参数 |

## 一、bundle 清单

`package.json` 的 `dsh.profile.bundles` 决定加载哪些能力。产品洞察需要至少这些：

```json
{
  "dsh": {
    "profile": {
      "bundles": [
        "@deepseek-ai/dsh-base",
        "@deepseek-ai/dsh-web-app",
        "@deepseek-ai/dsh-product-insight-bundle"
      ],
      "patchReload": "live"
    }
  }
}
```

| bundle | 作用 |
|---|---|
| `dsh-base` | 核心：会话、模型、工具、沙箱 |
| `dsh-web-app` | Web 界面与 Host 运行时 |
| `dsh-product-insight-bundle` | 产品洞察的模式与卡片 |
| `dsh-academic-bundle` | 学术洞察（可选） |
| `dsh-web-tools` | 外部搜索工具增强（来自 GitHub，可选） |

漏掉 `dsh-product-insight-bundle` 就不会出现产品洞察模式。

## 二、模型配置

`cordis.patch.yml` 里的 `llm-pi-ai` 段决定用哪个模型、参数如何。

### 三个关键参数

| 参数 | 作用 | 建议 |
|---|---|---|
| `contextWindow` | 模型能接收的上下文长度（输入 + 输出） | 取模型真实上限，如 `2000000` |
| `maxTokens` | **预留**给输出的 token 数 | 必须明显小于 `contextWindow` |
| `reasoning` | 推理档位：`off` / `low` / `medium` / `high` / `max` | 默认档或 `high` |

### 为什么 maxTokens 不能接近 contextWindow

产品洞察在调用模型前会判断：

```
输入 + maxTokens ≤ contextWindow
```

如果两者都配成 1,000,000，那么任何非空正文都会让不等式不成立——流程会把页面反复二分到 0，最终抛出「context model cannot fit source text」，表现是**整轮 0 证据、几十秒结束**。

### 档位越高，输出预算要越大

| 配置 | 结果 |
|---|---|
| 窗口 1M / 输出 1M | 证据提取全部失败（不等式永不成立） |
| 窗口 1M / 输出 32K + `max` | 证据正常，报告合成返回空文本（思考 token 吃光预算），降级为草稿 |
| 窗口 2M / 输出 1M + `max` | 正常出正式报告，单轮约 29 分钟 |

结论：**输出预留既不能等于窗口，也不能在小窗口下开高推理档。**

### 推理档位的实际代价

| 档位 | 单轮耗时 | 证据量 |
|---|---|---|
| 默认 | 约 8 分钟 | 90–120 |
| `max` | 20–30 分钟 | 100–160 |

多花两倍时间换约三成证据，按使用场景取舍。

## 三、环境变量

| 变量 | 用途 |
|---|---|
| `DSH_HOME` | 运行时目录，默认仓库内 `.dsh-runtime` |
| `WOWEI_GATE_API_KEY` | 模型网关密钥，名称与 `apiKeyEnv` 一致 |
| `TEMP` / `TMP` | Windows 下必须指向工作区之外 |

密钥不要写进 `cordis.patch.yml`，那里只写变量名。

## 四、配置改动何时生效

| 改什么 | 是否需要重新构建 | 是否需要重启 |
|---|---|---|
| `cordis.patch.yml` | 否 | **是**（模型清单在启动时读入） |
| `package.json` 的 bundle 列表 | 否 | **是** |
| `packages/**/src` 代码 | **是** | **是** |
| 提示词技能 `SKILL.md` | 是（属于打包内容） | 是 |

profiles 配置里虽然开着 `patchReload: live`，但模型清单属于启动时快照，改动后请直接重启，避免误判。
