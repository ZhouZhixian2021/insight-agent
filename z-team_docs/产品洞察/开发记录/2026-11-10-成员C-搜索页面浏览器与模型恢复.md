# 搜索页面浏览器与模型恢复

## 行为

普通 HTML 搜索解析成功时沿用原路径。结构未知时，每个搜索来源最多启动一次隔离浏览器，复用已经取得的 HTML，由受控 HTTP 读取脚本和其他资源，尝试解析渲染结果。仍无法识别时，将受限的页面文字、实际外部链接与查询交给当前会话模型，模型仅返回链接编号。程序验证编号后恢复候选网址；不能编造链接，不能将搜索摘要直接作为证据。

正常的其他来源结果不受失败来源影响。验证码不绕过；无法获取有效页面时仍如实失败。获得网址后继续通过原有网页正文读取、保存、证据抽取与核对流程。

## 边界与日志

- 浏览器开关沿用 browserEnabled，资源数量、正文长度、超时与取消沿用已有浏览器配置。
- 搜索识别输入默认最多 16,000 字符、60 个链接，可在来源配置调整；模型最多 1,024 输出 token，每个失败来源最多一次识别。
- 模型选择使用当前 Session，聊天搜索及后台调查均传递所属 Agent；识别请求和结果先保存到 Session。
- 新增事件只记录审计，不改变旧检查点结构。未保存发现阶段检查点时，恢复运行可能重复搜索识别。
- 没有新增模型服务或安装搜索插件；需要本机已有 Edge/Chrome 以及可用的当前模型配置。

## 验证

定向单元检查覆盖未知结构恢复、非 200 内容解析、验证码拒绝、真实链接编号及虚构编号拒绝、原有工作流。正式 Web 装配测试使用真实本机 Edge、固定 HTTP 响应和固定模型响应，验证 JavaScript 生成搜索链接后，经模型识别可以继续取得目标网页正文。此测试不代表真实搜索引擎或真实模型的成功率；未重新运行完整产品调查。

## 本地使用

重启 pnpm run insight:web 后，在产品洞察模式新建调查。此次开发仅保留本地，未提交或推送；旧调查不会自动重跑。
