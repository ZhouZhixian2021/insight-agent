# 按内容判断搜索结果与官方来源

## 修改范围

- 官方来源按已批准官方域名归属，不再要求候选发布方、网页自报发布方与开发者名称完全一致。原始发布方元数据继续保留。
- DuckDuckGo、Bing、Yahoo 搜索结果不再因 HTTP 状态码不是 200 而直接拒绝；有可解析的有效结果时按内容接收。
- 验证页面仍拒绝；非 HTML、截断响应和无法识别的页面仍不作为正常搜索结果。没有有效结果时，429 仅辅助说明限流原因。
- 保留批准域名、原文核对、版本、地区、时间和引用检查；未调整外部发布方规则，也未修改正文抓取阶段的 HTTP 处理。

## 验证范围

定向检查官方网页栏目名与开发者名称不同仍可通过，以及三种搜索源在非 200 状态下保留有效结果、202 验证页仍拒绝。旧会话的保存结果不会自动重算，需要新运行验证用户实际效果。
