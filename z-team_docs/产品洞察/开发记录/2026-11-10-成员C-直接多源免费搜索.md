# 产品洞察：直接多源免费搜索

## 目标与范围

撤回本轮未提交的 SearXNG 接入，产品预设直接请求 DuckDuckGo、Bing 和 Yahoo。保留既有产品调查编排、HTTP 优先与浏览器辅助读取、证据提取和报告流程。本次不提交、不推送。

## 实现

- 移除 SearXNG 适配器、部署配置、启动脚本、环境变量接线和相关测试；恢复原有 `insight:web` 启动脚本。
- 删除本任务创建的 SearXNG 容器、网络及 `.dsh-runtime/searxng` 配置，不删除 Docker 软件或其他容器。镜像缓存后续清理时 Docker 已关闭，缓存不参与项目启动。
- 同一获批查询并行请求三个免费 HTML 搜索入口，Yahoo 使用英国入口；不新增查询、不购买 API、不绕过验证码。
- 分别解析有机搜索结果，处理 Bing/Yahoo 跳转链接；按排名交错合并、清理跟踪参数、按网址去重，默认合计最多 10 条。
- 单源失败保留其他来源；全部失败明确报错；取消传播至全部请求。返回来源诊断并写入运行日志，失败或截断标记覆盖受限。
- 搜索摘要仅用于发现与筛选，后续仍需读取正文并核对证据。
- 为产品搜索启用可配置的代理 HTTP/1.1 兼容选项。通用 HTTP 读取器只新增可选传输参数；未启用的其他模式保持原行为，网址安全、同源重定向、超时与响应上限不变。

## 验证

- 使用项目 HTTP 读取器、实际本机代理执行 `Notion team permissions`：DuckDuckGo 10 条、Bing 10 条、Yahoo 7 条；合并去重 20 条，保留 10 条。
- 搜索解析、合并、失败隔离、取消、代理兼容及安全回归：18 项通过；包含固定输出快照。
- 正式 Web 产品预设接线：1 项定向测试通过，验证不依赖外部搜索插件。
- 构建产物生成通过；最终 Host/Client 类型检查 2/2 通过；定向静态检查与 `git diff --check` 通过。
- 双语 README 配对检查通过；本次仅运行定向检查，未调用大模型、未重跑完整产品调查。

## 已知限制

免费搜索网页没有稳定 API 保证，可能限流、验证或改版，解析失败不会被伪装为没有资料。三种搜索入口可能共享索引，不代表三套独立资料；数量增加不等于覆盖完整。实际请求沿用本地网络与代理设置，其他机器的可用性需按当地网络验证。每个并行来源默认 25 秒超时，单条查询最多发送三次来源请求，不无限重试。
