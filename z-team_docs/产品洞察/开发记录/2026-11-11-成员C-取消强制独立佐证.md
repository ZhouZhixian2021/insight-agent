# 取消强制独立佐证

## 完成内容

- 产品工作流取消逐题跨来源模型比对及专门的独立佐证补搜。
- 保留网页原文定位、摘录核对、语义支持审核及未回答问题的获批补查。
- 新调查进度卡显示来源发现与获取、证据提取、语义审核、报告生成四阶段，不再显示待执行的独立佐证阶段。
