# 产品洞察：免费搜索与浏览器读取

## 目标与范围

产品模式在本地接入不依赖 dsh-web-tools 的公开网页搜索与读取，保留原有获批计划、候选筛选、证据核对及报告流程。本轮不提交、不推送，保留此前本地修改。

## 实现

- 产品预设建立隔离的 Web 注册表，计划工具和后台调查使用同一套免费提供方，不影响其他预设的搜索选择。
- DuckDuckGo HTML 搜索返回标题、网址和摘要；摘要仅用于发现，不直接成为证据。区分限流、验证码、页面格式变化与确实没有结果。
- 静态页面先走 HTTP。空正文或显式依赖 JavaScript 的页面尝试本机匿名 Edge 渲染；其他系统默认 Chrome。
- 浏览器请求通过现有 HTTP 网址保护与代理策略，只允许 GET，限制时间、请求数和正文大小；取消时关闭所属浏览器。保留规范化正文和精确摘录核对。
- HTTP 提供方新增 JavaScript MIME 文本分类，用于获取浏览器脚本资源；未改变网址安全规则。

## 验证

- 免费搜索与 HTTP 提供方定向测试：64 项通过。
- 本机 Edge 固定页面：动态渲染和取消场景通过；不调用模型。
- 实际产品预设工具入口：确认免费搜索和网页读取不依赖全局外部搜索插件，通过。
- 一次公开 DuckDuckGo 搜索经本机代理成功，解析出 5 条结果，包括 Apple 官方规格页。
- 产物构建通过；Host 与 Client 两项聚合类型检查通过。
- 新增文件静态检查及三组中英文文档配对通过。

## 已知限制与本地使用

免费搜索没有付费搜索 API 依赖，但可能遇到限流、验证码或服务页面变化；模型使用仍可能收费。浏览器不能解决登录、验证码或所有复杂动态页面，不支持需要 POST 的交互；当前启用浏览器的判断是有限的正文检测，不保证每页完整渲染。

本轮没有运行完整真实模型报告。停止旧服务后重新运行 `pnpm run insight:web`，新建并选择产品洞察模式进行验证。无需新增搜索 Key，无需卸载其他模式可能使用的 dsh-web-tools。
