# A-S2 学术研究 Session 回放

## 本次目标

把 Session 中的已批准检索计划、批次决定、批次结算和运行终态重建为 A-S1 固定的恢复状态，不启动任何网络、全文或模型调用。

## 已完成

- 新增纯函数 `reconstructAcademicResearchRecoveryState()`；
- 以调用方给出的 RetrievalRun、ResearchBrief ID 和版本作为恢复目标；
- 使用目标运行第一条事实之前最近的 `academic/search-plan`，避免误用后续计划；
- 把 `schedule_batch` 决定与同编号结算配对为已完成批次；
- 将最后一个没有结算的批次展开为有序待处理候选；
- 从最近一次带覆盖的批次结算恢复逐题覆盖；
- 识别 `academic/run-settlement` 的完成和取消终态；
- 校验重复候选、重复或不连续批次、无调度结算、累计证据数倒退、终态后仍有批次事实、Brief 身份冲突等损坏历史；
- 新写入的批次结算附带当时逐题覆盖；旧结算没有该字段时保持兼容，返回空覆盖；
- 添加纯回放测试，覆盖可恢复状态、终态、旧事件、缺少计划、Brief 版本冲突、无调度结算和覆盖身份冲突。

## 边界

本次函数要求调用方已经取得完整且按持久序号排列的 Session 日志。它不读取 Session persistence，不取得独占写入句柄，也不把待处理 WorkVersion 解析成全文候选。A-S3 继续负责这些工作以及真正恢复执行。
