# 开发记录：HTML 导出与真实 Trace

## 范围与设计选择

成员 C（ykxy11）在 `dev/ykxy11`、团队主线 `5caa242e7a` 基础上开发当前版本的 HTML 和 Trace。A/B 的升级分支保持独立；已阅读 B 在 `upgrade/port-academic` 的 `d8e2108222` 反馈，采用 Session 与序号派生事件身份、正式 RPC 命名以及缺失事实保持未知的规则。

HTML 使用可离线打开的单文件，保留 Markdown。报告文字来自同一正式结果及检索披露，不增加模型生成。复用现有 Markdown 渲染器，通过惰性模板与允许列表输出章节、表格、目录、段落锚点、结论证据链接、原文和质量限制。导出移除脚本、活动属性和外部资源，外部引文仅保留为安全链接；图片改为替代文本。

Trace 在新研究运行中采集，不回填旧数据。运行、阶段、论文、逻辑调用与实际尝试分别记录；传输重试保留先前失败。全文获取、候选审核、准入、证据与综合模型调用提供真实观察。只记录允许的标识、状态、时间和净化失败类别，不复制请求、响应流、全文、URL 或凭据。总耗时、模型流执行和未知排队口径分别展示，不相加并发子项作为运行耗时。

## 输入、输出与失败

- HTML 输入为页面已有的正式报告，输出 `academic-report.html`；草稿、合成数据、质量问题及证据缺失说明始终保留，不因导出而提升审核状态。
- Trace 输入为当前会话与检索运行身份，输出阶段／状态筛选的安全页及操作详情。`academicResearch/traceList`、`academicResearch/traceDetail` 通过现有 Session 访问解析；游标绑定会话、运行、筛选与不可变事件水位，默认 50 条、上限 100 条。
- 旧研究没有 Trace 时显示缺失，不从时间、标题或当前配置猜测调用归属。重启或运行结束后仍未结算的操作保留最后状态并显示观测缺口。
- 关闭页面只中止 Trace 查看请求，不取消后台研究。刷新后可以从 Session 保存的观察重新读取。导出只包含当前已加载的安全页，不宣称全量审计导出。
- Trace 记录与观察回调失败不改变业务结果；无法保存的诊断不能视为完整。新版本事件为 `academic/trace-v1`，不覆写旧 Session 代际；旧读取程序如不认识此事件，会按既有规则拒绝读取。
