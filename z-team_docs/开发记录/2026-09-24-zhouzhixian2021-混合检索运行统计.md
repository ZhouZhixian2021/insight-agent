# 混合检索运行统计（A-H4）

## 本次目标与状态

在未提交的 A-H3b 工作之上完成 A-H4：把混合检索执行器的观察值和真实 ingestion 结果传到 Controller 的固定 `hybridRetrieval` 字段。当前为本地实现，未提交、推送或重启 Web；不代表已通过真实联网验收。

## 实现内容

1. `academic-workflow/src/pipeline-types.ts` 的搜索返回值可携带 `hybridObservation`。Controller 适配器不再丢掉执行器产生的观察值。
2. `academic-workflow/src/hybrid-search.ts` 记录实际核验结果、因来源未批准或预算耗尽而跳过的引用，以及核验后实际通过单查询结果上限的索引。没有引用或核验尝试时对应阶段为 `not_run`；成功引用旁的识别问题仍计入部分成功。
3. `academic-workflow/src/hybrid-run.ts` 从已经完成的查询和真实 ingestion 结果收集统计。没有已完成混合查询时不产生混合投影；旧计划继续兼容。
4. `academic-research-controller/src/hybrid-view.ts` 生成 JSON 安全返回值。沿用已有阶段、计数、候选与引用字段，候选和引用行新增可选 `query`。五类引用分别保留类型、规范值、实际核验 Provider、结果和受控原因；来源未批准、预算耗尽、重复引用不伪装成已尝试核验。
5. 发现 URL 删除用户名、密码、查询参数与片段；非法或非 HTTP(S) URL 返回空字符串。网页片段、生成式答案和原始诊断不进入浏览器投影，也不成为证据。分类来源失败继续保留在 `retrievalRun.failures`。
6. 取消保留此前已完成查询的统计，中断查询在 `retrievalRun.queries` 和限制说明中披露，不编造来源失败。总检索阶段不再把未结算的中断查询显示成全部成功。

## 固定计数口径

| 字段 | 口径 |
|---|---|
| `academicDiscoveredRecords` | 已完成查询的直接学术来源发现记录数之和 |
| `webDiscoveredUrls` | 已完成查询返回的 Web 候选 URL 条目数；跨查询重复出现分别计数 |
| `identifiedReferences` | 从候选中识别出的引用条目数，包含重复出现的引用 |
| `attemptedVerifications` | 实际发起并结算的引用核验次数 |
| `verifiedReferences` / `failedVerifications` | 已核验成功／失败的尝试数，不等于最终论文数 |
| `discardedWebCandidates` | 未识别出受支持引用的候选条目数 |
| `mergedDuplicates` | 实际进入 ingestion 的记录数减去不同论文数，在整轮候选上限应用前计算 |
| `deduplicatedWorks` | ingestion 去重后的论文数，在整轮候选上限应用前计算，与 RetrievalRun 覆盖统计一致 |

重复链接不增加论文合并数；因单查询上限被排除的记录不算合并；整轮上限不能把未保留论文伪装成重复论文。标题相似但没有共享精确标识的论文不会强制合并。引用行的 `merged_duplicate` 表示其核验记录属于一个真实合并组，不可按这类行数反推合并计数。同一引用跨查询仍可分别核验，本次没有扩大去重策略或改变调用预算。
