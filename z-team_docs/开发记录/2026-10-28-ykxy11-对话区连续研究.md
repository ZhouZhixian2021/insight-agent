# 开发记录：对话区连续研究

- 负责人：成员 C（ykxy11）
- 基线：最新 master（已包含 A 的逐轮计划审批修复）

## 实现

生产入口从侧栏研究弹窗迁入正常对话区。每次批准的学术计划对应独立研究卡，读取真实 Session／批准标识，等待原始轮次正常结束且会话空闲，在核对计划和已有任务后发起后台研究。中止或失败的轮次不自动启动，用户仍可明确选择执行。继续输入下一项研究时保留前一份卡片与报告；旧卡不能启动新计划或显示别轮结果。刷新、切换会话只解除监听；已保存任务按准确 ID 恢复，避免最近任务列表上限导致重新执行。进度、证据、Trace、增强操作和 HTML／Markdown 下载复用现有组件。旧弹窗及固定预览仅保留给测试。

## 范围与限制

未修改 A 的 Plan、Controller、工作流或 B 的来源及证据生产代码。C 包增加 Conversation、Chat、工具事件类型和测试运行时依赖，锁文件仅更新该包的四项工作区链接。当前仍遵守服务端单会话一个活动研究；若前轮尚未完成，后轮卡提示等待并提供刷新，不支持并行队列。自动启动由已挂载前端卡发起，关闭网页前尚未发起的计划不会变成服务端自动任务。

## 验证

定向验证覆盖两轮研究与报告隔离、原生／PTC 审批、被拒审批、StrictMode 启动去重、刷新恢复、取消与观察流生命周期。五个定向测试文件共 21 项通过，包含真实 Client Loader 装配及精简界面输出快照。完整构建九项通过，最终页面产物七项通过；变更文件静态检查、85 包依赖检查通过。文档检查 40 项首次通过，生成目录、事件图和记录链接三项修复后单独复验通过；最后修改的两组配对记录通过。全仓工作区约束仍受旧迁移目录缺少 package.json 影响；本地化检查仍报告既有 export-html.tsx 文档模板字符串，本次新增文案均使用字典。本次不重跑真实论文检索或模型实验，未作浏览器视觉验收。本次按用户要求提交至个人分支，由用户创建 PR。

## 真实使用反馈修复

真实会话已自动发起研究，但研究卡默认参与 Chat 的过程分组，被“已完成”折叠隐藏。卡片明确使用轮次正文位置，并在轮次完成后按结束序号排序。回归测试加入生产 processGroupDefinition，检查研究卡是正文根条目。使用该次真实 Session 只读重放，确认批准计划对应的卡片独立显示，未重新检索或调用模型。该运行本身无报告：三条查询的 OpenAlex 均返回 HTTP 429，arXiv 出现限流与超时，Web 发现失败，最终没有可用证据。来源问题未在 C 页面代码中掩盖或改写。
