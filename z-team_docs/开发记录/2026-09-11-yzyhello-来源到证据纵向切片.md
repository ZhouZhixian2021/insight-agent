## 目标

把方案层的「来源到证据」纵向切片落地为可运行、可测试的包：学术来源能力 seam、OpenAlex/Crossref/arXiv 三个 Provider、跨记录去重与版本合并、证据记录与证据卡片的确定性构造，使检索到的论文能够以稳定身份去重并进入可追溯的证据生产。

## 实际完成

- 新增 6 个包：
  - [`source`](../../packages/academic/source/README.md) — `ctx.academicSource` 服务、Provider 注册与顺序无关选择、`AcademicSourceError`。
  - [`source-openalex`](../../packages/academic/source-openalex/README.md) — 从纯适配库升级为网络 Provider，搜索公开 `/works` 端点。
  - [`source-crossref`](../../packages/academic/source-crossref/README.md) — Crossref `/works` Provider，DOI 折叠为小写裸形式跨源对齐。
  - [`source-arxiv`](../../packages/academic/source-arxiv/README.md) — arXiv Atom `/api/query` Provider，`fast-xml-parser` 解析，一律按预印本处理。
  - [`ingestion`](../../packages/academic/ingestion/README.md) — 精确键自动合并、模糊键标疑似重复、规范版本选择、稳定 id 索引。
  - [`evidence`](../../packages/academic/evidence/README.md) — 六种 `SourceLocator`、`EvidenceRecord`（等级-定位校验）、`EvidenceCard`（六分区）。
- 三个 Provider 通过小写裸 DOI 这一共同规范化形式，使 `ingestion` 跨源合并同一成果为单一 `AcademicWorkId`。
- 新增[学术来源子系统页](../../docs/subsystems/academic-source.md)，并登记 config-catalog、module-graph、tsconfig 与四条 [Agent Note](../../.agents/notes/implemented/architecture/)。

## 风险与限制

- 尚无可用的模型可见消费方：源检索、去重与证据构造都只能经包 API 调用，尚未写入会话或呈现给模型。

- Crossref 撤回检测、arXiv 分页等 Provider 细节延后。
