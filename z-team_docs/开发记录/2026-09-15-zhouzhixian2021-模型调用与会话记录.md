# 模型调用与会话记录

本次在 [workflow](../../packages/academic/workflow/README.zh.md) 实现 createModelEvidenceGenerator：复用 DSH 的模型服务、预备调用、消息估算及 Session 持久化。调用方明确提供模型配置和活动会话，不新增网络客户端或读取密钥的独立路径。实际产品入口挂接及真实模型联网验收尚未完成。

## 已实现

- A 的生成器接收 B 的请求和程序维护的论文来源，沿用 B、C 的接口及业务实现。
- 发送内容包括抽取要求、六栏 JSON 格式、研究问题及全部有序论文片段。记录实际配置、消息、身份、版本、哈希和输入估算后才发送。
- 请求及结果追加后，经 SessionStore 保存并从持久化存储读回核验；模型原始输出采用 DSH 的无损压缩流表示，保留异常或取消时已收到的输出。
- JSON 校验通过后交回 B 检查摘录并构建证据；validated 状态不代表语义审核通过。取消或截断不会当作正常回答。
- 按用户确认的策略，近似输入估算加输出预留超过模型容量时暂停该论文，其他论文继续；模型容量或输出预算未知时发送前失败，不自行编造上限。近似计数不能保证提供方一定接受。
- 按用户确认的策略，会话追加、刷新或读回失败会停止整轮；不能被普通论文错误处理吞掉，且优先于同时发生的取消。

## 正式应用调用入口
