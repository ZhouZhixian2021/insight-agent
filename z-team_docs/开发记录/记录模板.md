# 开发记录：主题

## 基本信息

| 项目 | 内容 |
|---|---|
| 日期 | YYYY-MM-DD |
| 负责人 | 姓名或团队称呼 |
| 协作人员 | 无或姓名列表 |
| 个人分支 | `dev/<成员>` |
| 任务分支 | 无或分支名 |
| 提交 | 提交号与标题 |
| 远程状态 | 本地未推送、已推送、PR 审核中或已合并 |

## 目标

用一段话说明本项工作要解决的问题和可观察结果。

## 实际完成

- 列出已经落地的产品、代码、测试或文档结果。
- 链接到负责该事实的源文件或正式文档，不在这里复制长篇说明。

## 实际检查

- 记录实际运行的命令及结果。
- 失败或跳过的检查写明原因，不写成已通过。

## 风险与限制

- 记录仍存在的产品限制、技术风险、外部依赖或需要团队决定的问题。

## 下一步

- 记录下一项可验收工作及其负责人；尚未分配时明确写“待分配”。
