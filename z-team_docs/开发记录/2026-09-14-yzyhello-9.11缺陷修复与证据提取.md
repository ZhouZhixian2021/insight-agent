## 实际完成

- 修复 [`ingestion`](../../packages/academic/ingestion/src/index.ts) 的三类去重问题：疑似重复记录现在会保留为独立成果；同一提供方记录重复检索时复用原版本；多个精确标识符桥接已有成果时合并身份和索引。
- 修复 [`source-arxiv`](../../packages/academic/source-arxiv/src/normalize.ts) 的版本信息丢失：保留具体 `vN` 记录 id、版本标签和 Atom `updated` 日期，同时继续使用无版本 arXiv id 做成果级去重。
- 加固 [`evidence`](../../packages/academic/evidence/src/locator.ts) 构造校验：拒绝反向摘要范围、表格或图片中的负页码，以及证据记录与定位器的版本不一致。
- 新增 [`extractEvidenceFromContent()`](../../packages/academic/evidence/src/extract.ts)：接收可定位的摘要或全文片段和调用方提供的 `EvidenceGenerator`，核验逐字引文确实存在于原文，构造 `SourceLocator`、`EvidenceRecord`，并汇总为研究问题、方法、数据集、指标、发现和局限六分区 `EvidenceCard`。
- 更新 evidence、ingestion、source-arxiv 的中英文 README 和既有 Agent Note，使实现、限制与 A/B 职责边界保持一致。
