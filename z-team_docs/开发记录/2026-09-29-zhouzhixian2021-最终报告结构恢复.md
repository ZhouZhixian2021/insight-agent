# 最终报告结构恢复

## 背景

真实学术调查已经完成检索、全文处理、证据抽取和报告合成模型调用，但没有交付最终报告。会话记录显示模型返回了完整 JSON，失败原因不是学术源或输出截断，而是 `limitations` 章节同时提供了 `statementIndexes` 和 `missingReason`，违反两者互斥的报告结构规则。原工作流只对传输、超时和输出达到上限执行恢复；完整响应的结构校验失败会在第一次尝试后直接结束。

## 本次改动

- 合成提示明确要求每个非主机章节只能采用一种形式：非空 `statementIndexes` 配 `missingReason: null`，或空 `statementIndexes` 配非空缺失原因。
- 结构解析错误指出具体失败章节，便于模型和日志定位问题。
- 新增整份响应结构恢复提示。它复用同一轮已经准入的证据和当前完整或精简输入，只加入不含原响应文本的解析诊断，并要求重新生成完整 JSON，不返回局部补丁。
- 合成模型策略增加可选的 `retryInvalidOutput`。学术研究控制器默认启用该策略，并继续受 `synthesisMaxAttempts` 的最多三次限制。
- 每次失败响应和恢复请求仍分别写入 `academic/synthesis-result` 与 `academic/synthesis-request`，不会重复检索、全文获取或证据抽取。
- 达到尝试次数后仍然结构无效时保持失败，不使用模板报告、不降低引用规则，也不把被拒文本当作有效内容。

## 验证范围

- 提示测试覆盖互斥规则、精确诊断和完整替代请求。
- 工作流测试覆盖第一次结构无效、第二次成功并生成报告，且检索与全文处理不重复。
- 工作流测试覆盖连续三次结构无效后按原规则停止，不产生报告。
- `academic-evidence` 无密钥会话快照固定首次结构无效、第二次整份生成成功的持久请求、失败结果和最终报告；`academic-limited-draft` 继续覆盖输出达到上限后的精简恢复。
- 中英文包说明和既有逐题洞察架构决策同步更新。

## 后续真实验证

合并并重启学术洞察 Web 后，重新运行一个真实研究请求。验收时应确认：若第一次合成结构无效，会出现下一条 `academic/synthesis-request`；最终有效响应能进入报告质量评估和 Markdown 渲染；检索、全文与证据抽取计数不因合成恢复增加。真实论文质量和独立语义审核不属于本次结构恢复范围。
