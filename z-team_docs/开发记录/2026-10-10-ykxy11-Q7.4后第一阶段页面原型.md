## 入口与功能

在主 Web 的 **Q6 只读演示** 中点击 **运行阶段与恢复演示**：

- 六类固定案例分别展示运行中、暂停、完成、有限完成、失败、取消；查看连接与运行状态分别记录。
- 关闭重开保留同一演示记录，切换演示记录或断开查看不自动取消；明确的“取消演示任务”才修改演示状态和取消来源。
- 展示发现、核验、初筛、排序与候选限制、全文、抽取、纳入和报告八步的输入、输出、单位与原因。
- 区分 70 条发现记录、30 篇候选上限、20 篇安排全文、12 条已验证证据、两篇部分可用论文及 4/4 问题覆盖。上限不等于通过数，部分可用不等于正式纳入，模型返回不等于证据核验成功。
- 未提供的处理数量、失败数量、阶段耗时和正式纳入数显示未知，不根据总耗时或其他阶段反推。
- 保留已有演示草稿，关闭重开后仍可查看和下载；取消不自动合成新报告。演示文件使用 `academic-demo-draft.md`，正文明确为合成 UI 样例。
- 未知取消来源保持未知，不推断为用户点击取消；已有成功证据不会在失败或取消时清空。

原型使用 C 包内的 `tests/fixtures/run-experience.sample.json`，客户端副本由一致性测试固定。部分数字参考实际事故摘要，其余案例明确为合成 UI 数据，不表示真实运行结果。本地状态仅保留到当前 Web 页面或插件释放；刷新不恢复，也不发起 Remote／模型调用。
