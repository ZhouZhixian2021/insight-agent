## 实现

- [analysis](../../packages/academic/analysis/README.zh.md)：复用输入准备函数，从至少两项独立研究生成归属明确的方法与发现对比；使用 A5 Claim、关联与快照。
- [eval](../../packages/academic/eval/README.zh.md)：检查来源关系、证据当前性、覆盖限制与明确的语义审核记录。
- [report](../../packages/academic/report/README.zh.md)：生成中文 Markdown 草稿，附结论、证据、版本、引用及限制；在最终交付入口重新核验。
- [ui-academic-research](../../packages/client/ui-academic-research/README.zh.md)：生成独立 HTML 文档，支持检索、证据展开和 Markdown 下载，不修改主 Web 页面或预设。
- [固定课题及人工审核表](../模块分工/member-c-report-benchmark.md)：两篇合成材料，覆盖全文与摘要证据。

## 边界

没有访问 OpenAlex/arXiv，没有另建论文或 Claim 数据结构。分析采用确定性的归属陈述整理，不调用真实模型，不推断领域共识、趋势、研究空白或性能排名。语义审核通过必须来自可信审核方，自动引用检查不会自动批准结论。

独立报告页没有实时研究进度、Brief 审核或 Session 恢复。实际工作流与主 Web slot 接入仍属于后续集成。本次测试是纯模块闭环与文档交互测试，不是完整 Session 会话测试。
