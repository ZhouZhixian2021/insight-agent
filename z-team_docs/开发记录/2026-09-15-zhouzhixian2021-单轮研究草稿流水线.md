# 单轮研究草稿流水线

成员 A 在 dev/zhouzhixian2021 完成[runResearchDraft](../../packages/academic/workflow/src/pipeline.ts)。用户确认先完成一轮检索，再于后续实现自动多轮检索；后者登记于[待改进事项](../模块分工/member-a-academic-workflow-call-plan.md#待改进事项)。本次不提交、不推送。

## 调用与边界

已批准 Brief → 一次检索 → ingestWorks 去重 → 调用方按范围选择版本 → 逐篇全文解析 → 哈希交接与证据抽取 → analyzeEvidence → generateReport 内部评测 → 草稿。

全部选择在全文请求前校验，拒绝未知版本、重复论文、撤稿与不允许的预印本。数量上限由本轮执行；日期和其他纳入排除规则由明确的 selectPapers 适配器负责。外部检索、获取、模型与时钟显式注入，未引入新的调度框架。阶段串行，不使用并发 worker。

哈希冲突只暂停对应论文，其他论文继续；全文或抽取错误记录版本和失败阶段，不把可能含敏感信息的原始错误直接写入报告。取消返回已完成论文及失败，不生成报告。查询失败向调用方抛出。本轮完成状态不代表研究质量合格，报告始终为 draft，语义审核为空，由 C 的评测给出 needs_review 或 blocked 等质量状态。

源码实现文件从具体文件导入，公共 index 只做导出，A 包内部没有反向导入 index 的循环。C 的现有内部循环导入未在本次修改。
