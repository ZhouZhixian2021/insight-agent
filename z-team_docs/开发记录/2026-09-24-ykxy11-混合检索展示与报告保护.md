### C-H2：终态阶段与统计

直接使用 `AcademicResearchRunValue.hybridRetrieval` 展示学术搜索、Web 发现、引用识别、核验、去重阶段及九项原始计数。继续展示原有全文、证据抽取、分析、报告质量和来源失败。

候选与引用展示查询、发现地址、五类引用标识、核验 Provider、实际状态和原因。未核验的官方链接不会显示为核验成功。URL 数、引用次数和去重论文数分别显示，不互相换算；不把仅用于核验的 Provider 计作直接检索来源。非法 URL 只显示文字。

返回值仍是终态投影。运行中不展示虚构阶段进度或百分比，缺少统计不填零。正式接口尚无“产生有效证据的独立论文数”字段；页面保留逐版本证据数量，不从版本数组拼凑该统计。报告生成仍以实际报告是否返回和既有质量状态呈现，不新增伪造的后端阶段。

### C-H3：报告披露与证据准入检查

- Web 报告预览和 Markdown 下载保留服务端正文及质量状态，附加实际渠道阶段、发现／核验／去重数量、实际 Provider、全文数、已批准查询预算、失败和覆盖限制。候选 URL 不写入参考文献；明确 Web 只用于发现，流程成功不证明覆盖完整。
- report 新增可选 `retrievalDisclosure` 展示输入，供宿主生成报告时附加同类披露。该输入是报告展示数据，不是另一套论文类型。浏览器仅引用其类型，在客户端生成附录，避免宿主代码进入浏览器 bundle。
- eval 新增可选 `admittedEvidence`：由可信生产端提供原始准入证据清单。引用记录的身份、版本、原文定位、内容、来源和抽取方式必须匹配，才能计入证据覆盖。未准入、内容被 Web 摘要替换或清单重复歧义均阻塞评测；单篇归属陈述也检查。
- report 在发现 `evidence_not_admitted` 时拒绝生成，包括草稿，避免这些记录进入引用和参考文献。准入通过仍不等于语义审核通过。
