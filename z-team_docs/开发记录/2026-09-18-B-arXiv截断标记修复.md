## 目标

修复 2026-09-18 搜索稳定性记录中验证的 arXiv `truncated` 失真：provider 固定返回 `false`，即使 Atom feed 的 `<opensearch:totalResults>` 超过实际返回条目数（实测 totalResults=6、返回 5 条）也不上报，导致 `searchAll` 覆盖统计虚报完整。

## 实际完成

- [parseArxivFeed](../../packages/academic/source-arxiv/src/parse.ts) 返回值从条目数组改为 `{ entries, totalResults }`：解析 `<opensearch:totalResults>` 为安全非负整数；元素缺失或畸形时为 null，缺失不当作 0。
- [provider](../../packages/academic/source-arxiv/src/provider.ts) 改为 `truncated = totalResults > works.length`；seam 自身 `maxResults` 截断仍由 seam 标记，两层语义不变。
- 新增 `ArxivFeedResult` 类型（[types.ts](../../packages/academic/source-arxiv/src/types.ts)）并从包入口导出；仓库内消费方仅本包 provider 与测试，已全部更新。
- 双语 README 补充 `truncated` 语义与 `ArxivFeedResult` 行，并重录 [README.i18n.yaml](../../packages/academic/source-arxiv/README.i18n.yaml)。
