## 已实现

1. 在主 Web 侧栏增加“学术研究样例”入口，使用现有 Modal 与 locale 服务，支持中英文。页面始终披露合成数据和未连接真实请求。
2. 运行中仅显示等待和“取消样例运行”；取消保留已有论文结果但不展示报告。另提供部分成功、检索成功、全部失败、阻止交付与请求异常的固定展示场景。
3. 分开显示运行状态、检索结果和报告质量；completed、success 均不代表人工审核通过。
4. 直接展示返回的发现量、去重量、纳入量、全文/摘要/元数据量、失败操作数、数量截断及覆盖限制。providerBreakdown 为 null 时明确未提供，不推算逐来源计数。
5. 来源与运行失败、论文处理失败分别展示；显示失败来源、操作、原因、是否可重试。不会自动发起重试。
6. 展示报告质量问题、结论评测方法与理由、置信等级及依据、不确定性、证据摘录、来源链接、定位标识、实际版本、获取时间和质量说明。支持搜索、结论跳转证据、展开与 Markdown 原文下载。
7. 缺报告、缺证据、缺摘录、没有搜索结果等情况有明确提示；返回文字按文本渲染，来源链接仅允许 HTTP(S)。

## 实现边界与集成说明

主体位于 packages/client/ui-academic-research。局部 RunValue 组合现有 AcademicResearchRunValue 与共享 RetrievalRun；固定样例的品牌类型转换只在夹具边界进行，测试确保内容与 A 的 JSON 完全一致。

没有修改 Academic Model、来源、工作流或 Controller 的类型/业务源码，也没有建立新的论文或证据数据结构。真实 Remote 尚不包含 retrievalRun，因此本次没有接入真实请求、服务器取消、Session 恢复、进度流、自动重试或审核操作。后续由 A 扩展正式返回值，再替换固定数据入口。

为了完成主 Web 实际验收，还包含下列集成配置：

- 前端包 manifest、TypeScript 引用、pnpm-lock.yaml 中对应 importer。

根配置与锁文件请 A 在合并时重点复核。本次跨目录变更均服务于主 Web 装配、验证及文档同步。
