# 成员 C：报告最小闭环基准与人工审核表

## 基准课题

课题为“检索增强生成：分项评测与失败定位”。第一版使用两篇明确标注为虚构的合成论文，验证软件流程，不代表团队已经选定正式研究课题，也不代表真实学术结论。

输入由[固定基准](../../packages/academic/report/tests/benchmark.ts)构造：A 提供全文片段，说明分别记录检索覆盖和回答正确率；B 仅提供摘要，指出总体得分不能区分两类失败。两者均没有可供数值排名的完整实验设置。

## 期望输出

- 生成方法和发现两条跨论文对比，保留每篇论文的陈述归属。
- 每条对比均关联两项研究的具体证据、版本、哈希和来源定位。
- 摘要证据限制置信度，不能宣称某方法性能最好、领域已有共识或没有相关研究。
- 报告必须显示草稿、合成样例、待语义审核，提供参考文献和原文证据附录。
- 删除一条所需证据、改变哈希或撤回版本时，质量状态不得为 ready；最终交付必须拒绝。

## 人工审核表

| 审核项 | 通过标准 | 不通过时处理 |
|---|---|---|
| 来源真实性 | 正式研究使用真实、可访问的来源；样例始终标记合成 | 不作为正式成果 |
| 原文支持 | 每项陈述可在引用片段中找到，未扩大原意 | 修改或删除结论 |
| 范围与条件 | 论文归属、数据集和评估条件明确；缺失处如实披露 | 降低结论强度或标记不足 |
| 反对证据 | 已知反对结果保留，不能只选支持材料 | 补充冲突说明 |
| 引文追溯 | 结论、关联、快照、证据、定位和版本对应 | 阻止最终交付 |
| 置信理由 | 解释证据深度、覆盖范围和不确定性 | 退回修改 |
| 报告可读性 | 摘要、对比、局限、参考文献与证据附录完整 | 调整报告结构 |
| 导出一致性 | 下载内容与查看的 Markdown 一致 | 修复导出 |

自动评测负责结构、版本和明确规则检查，不代替上述语义审核。真实审核由调用方传入 ClaimAssessment；测试中的 synthetic-test-review 仅供测试，不能当作用户批准。
