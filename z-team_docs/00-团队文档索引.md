## 用途

`z-team_docs` 是 insight-agent 三人开发团队的中文共享目录，用于保存协作规则、成员与分支信息、开发记录以及团队常用资料入口。产品行为、架构决策和运行时代码仍由仓库原有位置负责，本目录通过链接引用它们。

## 文件归属

| 内容 | 保存位置 | 原因 |
|---|---|---|
| 团队 Git 规则、成员分工、开发记录 | `z-team_docs/` | 由三人团队共同维护，只要求中文可读。 |
| 产品使用说明和架构计划 | `docs/` | 受仓库双语配对、链接和文档检查约束。 |
| 已实施架构决策 | `.agents/notes/implemented/` | Agent Note 是该类决策的仓库规定位置。 |
| Agent 提示词、Skill 和配置 | `packages/` | 它们属于运行时输入，必须随代码和测试一起演进。 |
| 启动脚本 | `scripts/` | 它是可执行入口，不是团队说明材料。 |

## 维护规则

- 本目录使用中文，命令、路径、分支名和代码标识保持原样。
- 每项开发工作单独建立记录，文件名使用 `YYYY-MM-DD-主题.md`；多人同日开发不同任务时，在主题前加入成员名或 GitHub 用户名。
- 开发记录只写实际完成、实际检查和真实风险，不复制完整产品说明或架构文档。
- 不在本目录保存 API Key、令牌、密码、`.env` 内容、会话数据、用户文件或构建产物。
- 正式文档变化时更新原文件；本目录只维护入口链接和团队工作信息。
