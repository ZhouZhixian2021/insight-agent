# Agent Note: Web 选择论文进行二级证据增强

Status: implemented

[English](2026-10-15-academic-web-enhancement.md) | 中文

## Problem

草稿后的增强 Remote 每轮只允许一次持久选择，但 Web 查看器没有选择操作或新增证据界面。RPC 结果丢失不能触发再次增强或丢弃原报告。

## Decision

Web 面板为一篇符合条件的论文版本调用现有 Remote，同步本地锁阻止重复点击。既有 Session Remote 提供快照和更早历史页；纯投影读取当前运行的选择、结算及已核验增强片段。摘录保留原 ID、版本、定位和来源等级；选择与结算序号限制排除其他片段。不改变 Controller、Model、工作流或 Remote 字段。

面板保留一级报告及审核状态，区分本地请求活动、仅有选择而未结算、完成或部分成功、失败、取消和 RPC 结果未知。历史读取失败时禁止触发，已有持久选择不再提供启动操作。关闭只取消本次增强请求并忽略迟到回调；重新打开读取持久历史而非重新执行论文。

## Alternatives considered

用数量生成证据文字会虚构来源；替换一级报告会丢失用户已有交付。传输失败后自动重试可能在选择状态未确认时再次执行。新增轮询或历史接口会重复既有 Session 日志读取能力。

## Consequences

新增证据界面独立于报告生成和语义审核，不把未结算选择声称为正在运行。失败结算可以记录零新增，而早先已核验片段仍可读取；两种事实分别展示。初始历史发现读取既有 Session 分页，展示不增加模型调用。真实论文模型质量及整轮研究验收仍需联合完成。

## Verification

定向组件测试覆盖一次触发、终态、重新打开、历史失败和卸载清理。固定论文浏览器场景通过真实 Remote 传输和 Session 日志使用脚本化增强结果，检查 Markdown 保留及新增摘录恢复，不运行完整研究或真实模型。
