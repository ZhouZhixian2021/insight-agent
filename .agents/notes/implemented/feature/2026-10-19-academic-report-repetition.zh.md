# Agent Note: 学术报告段落复用

Status: implemented

[English](2026-10-19-academic-report-repetition.md) | 中文

## Problem

经校验的同一陈述可被多个方向分区和逐题回答引用。每个位置完整展开会重复分析正文及条件。证据附录沿用输入顺序，暴露内部排列，缺少面向读者的论文组织。

## Decision

首次展示完整分析段落，保留锚点、适用范围、不确定性及支持、相反和背景证据；后续位置链接到该段落。执行洞察使用同一身份登记；定量表链接到段落并保留实验条件和来源定位。不按文字相似度合并不同陈述，分析篇幅对每段展开的陈述只计算一次。

附录使用明确的中文区域按论文标题排序，同标题按论文身份打破并列。每组保留已有参考文献编号，组内按版本身份排序，同版本证据保留输入顺序。证据标识、摘录和定位保持不变。标题缺失时显示论文身份。渲染不修改生产方记录或审核状态。

## Alternatives considered

重复完整正文使章节独立可读，却放大了有限的研究发现。删除文字相似的段落可能混淆不同结论。由渲染器生成简短替代结论会引入未经核验的分析。

## Consequences

读者通过交叉引用查看共享论证。首次位置由报告遍历顺序决定，不新增语义分类器。附录排序不改变引文编号。不需要修改模型调用、Remote、共享类型或工作流。

## Verification

报告夹具检查共享陈述正文仅出现一次、段落引用有效、输入不变，以及证据输入反序后仍按标题分组。包内预期报告记录输出。
