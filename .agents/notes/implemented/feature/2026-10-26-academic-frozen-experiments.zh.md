# Agent Note: 学术研究 C 模块固定材料实验

Status: implemented

[English](2026-10-26-academic-frozen-experiments.md) | 中文

## Problem

重复完整研究既耗时，又会改变检索、证据和模型输出。C 模块报告实验需要固定上游材料，并识别实际代码，不能改写生产 Session。

## Decision

开发工具按 Session 文件和 researchRunId 选择已完成研究，使用现有解码器读取拼接 Zstandard 帧，仅导出所选研究事实、模型可见文本、安全生成配置及 Trace。尾部未完成或读取期间源文件变化时拒绝完成。不会导出聊天请求头、凭据或推理流。新目录和文件哈希保护原有固定包。

分析输入与原始报告是保存事实。报告参数由原分析回答、检查点和报告重建，保留 Claim ID，重新建立关联，从 Markdown 恢复检索披露。说明文件标出全部重建部分，未记录的原运行代码版本标为未知。C 源码快照识别未提交修改，不恢复原始全文字节。

离线重放执行源码报告／评测及独立页面，不调用模型。对比忽略重新生成的评测 ID，保留输入时间。准备提示只写出当前提示，导入另行记录的回答支持受控分析实验，不增加 Provider 执行。私有产物默认保存在已忽略的 .artifacts 目录。

compare-writing 对同一固定输入的两份另行撰写实验稿生成报告，将选用证据集合视为输出，不强行保持相同。显式任务模板和开源思路策略保留适用条件、真实表格值及原始摘录。实验正文与源证据及生产 Claim 分开，产物始终为草稿；机械检查不代表语义审核通过。准备的提示是可复用规范，不伪装成 Provider 执行日志。另行提供的示例记录实际作者。真实模型比较通过独立私有 dsh profile，沿用原模型入口与生成设置，使用固定共同材料及 Session 请求／结果记录。相同后处理器隔离未知证据引用，不猜测修复；原始模型输出保持不变。最终引用集合是观察结果，各运行一次不能证明统计意义上的提升。

## Alternatives considered

重跑完整工作流会把代码效果与上游变化混在一起。复制整个 Session 会导出无关上下文并保留过多数据。把解析旧输出当作新模型回答会歪曲实验含义。

## Consequences

本轮是开发工具，不新增生产网页按钮、模型入口或自动导出。它扩展[Trace 适配](../architecture/2026-10-21-academic-trace-adapters.zh.md)和[HTML 交付](2026-10-26-academic-html-delivery.zh.md)，不取代原决定。测试覆盖源文件不变、隐私过滤、回答导入、固定输入、重复报告及多帧解码。所提供 Mixup/CutMix 运行用于真实固定材料重放，独立预览不代表主网页视觉一致。
