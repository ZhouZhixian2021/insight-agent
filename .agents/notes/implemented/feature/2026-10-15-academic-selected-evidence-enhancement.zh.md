# Agent Note：按所选论文补充二级学术证据

Status: implemented

[English](2026-10-15-academic-selected-evidence-enhancement.md) | 中文

## 问题

对每篇论文自动执行完整深度证据抽取，会延迟首份可用草稿，也会让整轮运行受片段模型失败影响。即使后续增强失败，一级证据仍须可用。

## 决策

已批准的一级流程先返回有限草稿。独立的 `academicResearch.enhanceEvidence` Remote 接收已完成检索运行中的一篇论文版本，每轮最多选择一篇。控制器确认所选论文已有持久化证据，重新获取全文，并在记录选择前核对内容哈希与原版本一致。随后工作流通过现有模型调用记录与已核验证据片段持久化入口，调用 B 的完整深度分段增强。默认整次最多 180 秒、单次尝试最多 60 秒、输出最多 8,192 tokens。选择、核验后的新增内容及终态结算均写入 Session。失败或取消保留原证据和报告；增强不会自动批准或重新生成报告。

一级证据准入也把已核验的证据—问题关联传给洞察分析和报告生成，让有限草稿能够区分已支持的问题与缺口。第 5 版计划按 Brief 问题顺序，把逐题审核过的别名词传给 B 的一级片段选择器；这些词只改变调度顺序，范围决定和证据仍独立核验。旧计划保持问题原文的回退方式。

## 考虑过的替代方案

**先自动增强所有纳入论文再生成草稿。** 不采用，因为首份结果会依赖每篇论文的完整深度抽取。

**用增强结果替换一级证据。** 不采用，因为局部失败不能抹去已核验摘录、来源或现有草稿。

## 结果

该 Remote 是后台选择接口；Web 选择控件及经独立审核的升级报告留待后续。每轮一篇的限制持久有效，包括增强失败后。针对性工作流与控制器测试覆盖问题关联传递、增量证据和单次选择结算。这些测试不代表已完成真实模型运行验收。
