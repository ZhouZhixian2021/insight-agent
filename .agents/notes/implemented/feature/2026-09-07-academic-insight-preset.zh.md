# Agent Note: 学术洞察预设

Status: implemented

[English](2026-09-07-academic-insight-preset.md) | 中文

## 问题

内置预设列表提供编码组装，但没有垂直研究组装。研究技术前沿的用户只能从带 Shell 和编排工具的编码 Persona 开始，报告方法也只是未受跟踪的 Prompt，不能随所选 Agent 一起分发。

## 决策

内置列表包含 `academic`：一个单 Agent 研究预设，提供文件工具、网页搜索和抓取、用户提问、Skills 及上下文压缩。它不提供 Shell、委派、目标、待办、Ralph 和工作流工具。内置 `academic-insight-report` Skill 负责证据规范和自适应报告层级，其格式来自用户提供的参考报告。

新的学术洞察会话使用 `initialActive: true` 和一次 `missingExitRetries` 提醒来配置计划模式。Agent 会在首个请求前把需求整理为内置 Research Brief 字段和执行计划，只允许少量预检索，并把完整计划放入 `exit_plan_mode` 参数，不发送普通文本预告。如果它没有调用评审工具就停止，一条已记录的同轮提醒会要求它提交计划；次数上限可防止无限重试循环。批准后在下一步骤开始研究；拒绝则让会话留在计划模式。已有日志选择或请求头会阻止初始化，因此恢复和退出计划模式后的会话不会自动重新进入。

Web 选择器通过共享的内置预设字典将它本地化为 **Academic insight** / **学术洞察**。该预设在当前选择器中保持同级，因为此界面选择的是会话的完整插件组装；系统不会只为一个垂直组装再引入业务分类和会话状态字段。

仓库的 `insight:web` 启动入口在进入受支持的 Web profile 前，将自身的 `.dsh-runtime` 指定为 `DSH_HOME`。因此，该仓库的 profile、已安装 bundle、会话、设置、凭据和工作区记录不会与使用账户级默认 home 的其他检出共享。

## 证据策略

Skill 区分元数据、摘要和全文支持，将检索内容视为不可信数据，要求稳定来源链接，并禁止用搜索摘要支持实验数值或发表状态。初始组装依赖现有通用 Web Provider，并明确没有学术数据库和 PDF Provider。

## 考虑过的替代方案

**在 Agent 预设上方增加业务选择器。** 一个业务不足以支撑第二套选择模型、新的业务分类和会话状态字段以及另一个空会话控件。现有预设列表已经负责完整的每会话组装，并公开本地化名称与描述。

**原样复制标准模式，只修改名称。** 这会授予首版研究方法既不需要也未验证的 Shell、子代理、Ralph 和工作流能力。较窄的组装让 MVP 的权限与限制更加明确。

**先实现 OpenAlex、PDF 解析和证据数据库，再公开预设。** 这会推迟对研究行为和报告层级的验证。预设明确说明摘要级能力限制，后续能力 Provider 可以在不改变会话选择模型的情况下扩展它。

## 后果

用户可以在 Web 会话开始前选择可见的学术研究 Agent，并获得随预设分发的报告方法。用户无需输入 `/plan` 即可说明研究需求，检查或修改规范化范围，并在完整检索开始前批准执行。MVP 能够检查本地资料和通用网页来源，同时不授予命令执行或多 Agent 编排能力。它尚不能承诺学术语料召回率、段落级核验或持久证据复用；这些能力需要后续 Provider 和测试。
