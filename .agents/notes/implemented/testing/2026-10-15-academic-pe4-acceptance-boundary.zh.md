# Agent Note: Academic PE4 验收边界

Status: implemented

[English](2026-10-15-academic-pe4-acceptance-boundary.md) | 中文

## Problem

最小证据、报告渲染和所选论文增强的组件检查都通过时，获批问题与证据的关联仍可能在工作流交接中丢失。脚本化成功也不能证明真实来源覆盖、模型质量或耗时。

## Decision

工作流级固定矩阵让三个不同的获批课题经过摄取、全文解析、证据核验、合成和草稿评测。每题在另一篇论文失败后保留一条关联到问题的已核验摘录，并让缺乏支持的问题保持未回答。另设零证据场景，在合成前停止。输入和模型响应均明确标记为合成；Controller 和 Web 契约仍由各自聚焦检查覆盖。

## Alternatives considered

把各包测试当成整轮验收会漏掉跨模块的问题关联。把合成摘录当成真实论文发现会夸大学术与性能证据。每次代码修改都重跑三轮真实研究则耗时且依赖外部服务。

## Consequences

固定矩阵低成本捕获交接回归，并保留草稿与正式交付的区别。三个课题的真实审批、学术检索、模型抽取、报告质量和所选论文增强仍需独立验收。B 的同论文基线完成前，A 不能宣称已有经测量的速度提升。
