# Agent Note: Web 监听会话后台学术任务

Status: implemented

[English](2026-10-12-academic-background-web.md) | 中文

## 问题

浏览器监听不能拥有长时间研究任务：关闭弹窗和切换会话不能终止服务器执行，重开的页面需要读取保存的结果，而不是再次研究。

## 决策

生产表单使用 Controller 的后台启动、列表、读取、监听及取消接口。挂载时读取会话记录，优先选择运行中的任务，否则选择最新记录，并支持查看历史记录。监听控制器只管理启动请求及监听生命周期。显式取消通过独立命令执行，以服务器状态为准；停止监听不发送取消命令。启动响应丢失时重新读取记录，确认后才能再次启动。中断记录不会自动续跑。

每次监听绑定会话、后台任务、检索运行及 Brief 身份。进度和 Q6 序号分别递增，保留最多 20 条本次观察到的进度。断线保留已有观察，用户可以显式重新读取。服务器任务完成、检索结算与报告审核分别展示；没有当前计划批准也可查看保存的报告。

## 考虑过的替代方案

**通过重新执行恢复页面。** 不采用，因为会重复研究和消耗；恢复读取已保存任务。

**监听断开就取消。** 不采用，因为服务器任务和浏览器监听分别拥有生命周期。

## 后果

页面不需要在浏览器中持久化任务。刷新恢复依赖 Session 记录和 Controller；无法读取任务列表时禁止重复启动。重连只读取保存状态，不调用检查点续跑。固定生命周期预览仍是明确标注的合成演示。

## 验证

定向客户端测试覆盖重新挂载恢复、弹窗关闭、会话切换、显式取消、中断、启动响应丢失、监听重连及迟到响应隔离。现有真实 Loader/Web 场景在外部发现阶段关闭并刷新页面，重开同一后台任务，并在没有再次启动的情况下读取最终结果。来源使用合成数据，不代表真实来源或模型质量验收。
