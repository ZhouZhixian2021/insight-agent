# Agent Note: 学术 Trace 适配器

Status: implemented

[English](2026-10-21-academic-trace-adapters.md) | 中文

## Problem

学术诊断需要在两条基座升级路线间关联研究、论文和调用尝试。已有 Session 观测缺少部分运行关联与独立执行计时；直接依赖原始事件的界面需要按路线重写，也可能制造历史事实。

## Decision

共享品牌类型放在 academic-model，并提供公开的仅类型 trace 子路径。当前适配器使用显式分配的检索运行身份，在所属 Session 保存安全的 academic/trace-v1 观察记录。全文获取、候选审核、准入、证据与综合操作分别报告调用及尝试，传输重试保留原失败。阶段和论文记录使用工作流观测身份。Controller 标准化当前 Session 记录，trace-query 对统一观察分页与统计，不导入 Session 类型；Web 面板只消费受范围约束的 Remote 结果。

游标绑定 Session、运行、筛选条件及不可变事件水位。汇总描述同一水位，不相加并发子项耗时。未知排队耗时保持 null；已关闭或中断运行保留未结算操作状态，并提示观测缺失。查询与导出不含提示词、响应流、URL、凭据或原始错误。诊断不决定证据准入或报告审核。版本化事件必须被读取程序认识，旧程序遇到未知事件会拒绝日志，而非静默声称历史完整；不覆写已发布代际。

## Alternatives considered

在界面解析 Session JSONL 会让展示依赖持久化代际并暴露原始内容。按标题或相邻时间戳推断调用会合并无关操作。把完整请求复制到第二份存储会重复保存敏感数据。[Session 谱系与事件追踪](../../implemented/feature/2026-07-13-session-query-tracing.zh.md)继续作为独立的关系查询。

## Consequences

A/B 可以复用共享类型、观察查询与展示，并适配各自基座观察点。历史运行无 Trace 时返回明确缺口，不重跑模型填历史。不同片段生成器调用仍为独立逻辑调用，Provider 搜索内部与草稿后二级增强尚未完整追踪。新适配器必须提供事实，不能推测这些缺失关系。范围夹具回放、模型传输重试测试和真实 Web 组合约束预期行为。
