# Agent Note: 学术分析输入准备

Status: implemented

[English](2026-09-14-academic-analysis-input.md) | 中文

## Problem

单条学术记录具有类型，并不保证跨记录引用正确。跨论文分析还需要区分缺失的实验信息和已报告的值，同时避免把多个版本当成独立论文计数。

## Decision

[分析库](../../../../packages/academic/analysis/README.zh.md)按成果和实际版本生成只读视图。证据关联检查失败的条目被排除，其他条目和明确限制继续保留。筛选后的卡片是视图，不替代持久记录。对象 ID 重复会拒绝整个批次，因为任意选择记录会导致证据身份不明确。

模块消费共享 A1–A4 类型，仅定义整理阶段的内部输出类型。它不创建 Claim 模型、模型可见请求或 Session 事件。已有[证据构建决策](2026-09-11-academic-evidence-construction.zh.md)继续负责生产端抽取；本决策补充批次关联检查，不取代任何现行记录。

## Alternatives considered

**一条引用错误就拒绝整个批次。** 这会丢弃其他可用论文。按条目排除既保留部分进展，也能报告具体受影响的引用。

**根据指标名称相同推断可比性。** 数据集版本、评估条件和证据深度可能不同。整理阶段记录缺失字段并保留原始证据，不对结果排名。

## Consequences

消费方获得可追溯材料和问题，但仍须执行 Brief 要求、评估语义并选择可比实验。纯函数不修改输入；只读引用不提供深层运行时冻结或持久快照。撤稿排除对应版本；哈希比较只检查传入批次中的已知哈希，不判断外部版本是否更新。

## Testing

[固定合成测试](../../../../packages/academic/analysis/tests/prepare.spec.ts)覆盖部分失败、缺失引用、归属、证据等级、不可用字段、重复身份、多版本和空输入，不调用模型或网络。
