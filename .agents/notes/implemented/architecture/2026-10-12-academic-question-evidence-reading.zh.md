# Agent Note: 问题导向阅读保持生产方证据不变

Status: implemented

[English](2026-10-12-academic-question-evidence-reading.md) | 中文

## 问题

可追溯引文本身不能解释与研究问题的关系。重复摘录可能挤占互补发现，不同数据集可能被误判为结果冲突。引用身份正确不能证明语义支持。

## 决策

[PaperQA2 算法](https://github.com/Future-House/paper-qa#paperqa2-algorithm)提供问题导向证据阅读的参考；本实现保留现有的一次综合调用，不引入它的搜索或重排流水线。

分析在现有综合请求中增加内部证据阅读指引。生产方卡片分区表示内容类型，不赋予相关性或支持关系。同源重复组保留所有 ID，要求论文、版本、定位、Provider、URL、深度、哈希和原始摘录完全一致。完整及精简提示使用准入证据；精简恢复保留卡片条件及测量上下文。模型选择代表证据，在已有关联理由中解释对问题的贡献，区分可比较结果、条件差异、潜在冲突和可比性未知。不改变输入结构、模型调用阶段或共享类型。

报告按已有支持、相反和背景关联分组，在保留论证旁展示转义后的原文及来源身份；没有相反关联表示仍未知。引文和重复段落不计入分析正文篇幅。排版不创建证据，也不授予审核状态。

评测逐条要求跨论文 Claim 获得两项不同论文身份的支持，拒绝重复的结论／证据关联，并要求审核恰好覆盖唯一的快照证据。固定人工案例覆盖范围扩大、因果误判、遗漏相反发现、从缺少证据推断否定和不可比数据集；负面审核验证交付规则，没有审核时保持待审核。

## 考虑过的替代方案

**新增独立模型重排或自动审核调用。** 延后，因为模型执行、预算和 Session 持久记录归 A；现有综合调用可以直接使用这些指令，无需新增阶段。

**依据关键词或卡片分区赋予相关性。** 不采用，同一方法段落可能回答一个问题，却只为另一个问题提供背景。

**合并重复来源记录或自动认证语义正确。** 不采用，因为证据身份及独立审核必须可检查，结构检查不能证明含义。

## 结果

A、B 继续提供现有材料。阅读与报告更容易检查，但语义质量依赖配置模型及独立审核。固定案例验证规则，不证明真实模型提升。模块内报告测试和现有 SDK 会话场景固定输出及持久提示。不增加检索、向量、模型传输或 Web UI 修改。
