# Agent Note: 在证据与报告之间按研究问题生成洞察

Status: implemented

[English](2026-09-20-academic-question-synthesis.md) | 中文

## 问题

证据抽取核验通过后，仍可能只生成未回答批准研究问题的简短模板。来源陈述、跨论文推理与报告交付需要独立职责和可观察的失败结果。

## 决策

已完成搜索批次按轮转顺序合并并精确去重，全部已返回论文先经过日期、版本状态及全文地址初筛，再让合格论文占用全局候选名额，避免前面的不合格记录挤掉后面的可用论文。单查询发现和核验预算独立保留；地址解析不获取全文，也不证明全文能够解析。去重计数保留全部已返回论文，已选论文 ID 表示初筛后的候选池。流水线回归测试与无密钥 academic-hybrid-search 会话回放固定这一顺序。

工作流处理有界候选池；启用提前停止时，证据准入同时满足 Plan 两项下限即停止，否则处理至成功纳入上限。每项成果只尝试一次；排除、失败、暂停或空证据后可继续下一篇。充分性和可用论文计数由同一个准入检查负责，避免把下载全文误认为补选已达标。候选耗尽会明确披露，不创建额外搜索或降低计划要求。配置的时间上限取消未完成操作并保留已结束的观察。证据不足时生成草稿仍与补选分开处理。

Brief 的 includedWorkTypes 筛选版本状态，不表示会议或期刊类别。计划使用 preprint、accepted_manuscript 与 version_of_record，同时保留预印本许可和撤稿排除规则。控制器在审核前的工具分发阶段检查带围栏的 Academic 计划，并在读取已批准计划时复用分析要求检查。具体字段诊断要求修订计划并重新批准；不通过类别到版本的自动转换改变已审核范围。严格的发表类别筛选需要当前模型尚未提供的来源元数据。

分析库准入版本、定位和已知哈希一致的证据，按可用证据统计独立论文，并在发送请求前解析支持的 Plan 章节。未达到批准的论文或全文下限时，continue_with_warning 允许已有可用证据进入分析；stop_for_review 和零可用证据仍被阻止。带警告准入不满足补选提前停止条件。提示披露具体不足，逐题缺口保持可见，报告显示支持论文数量不足并禁止正式交付。获批 Brief 和证据完整性检查不变。检索与全文解析保持原有能力。

逐题洞察沿用会话选择的模型，与抽取共用明确的输出预算，但抽取和合成使用独立的恢复策略。论文抽取可以对输出达到上限以及配置的 TRANSPORT 或 TIMEOUT 故障执行有界退避重试；瞬时故障重试复用同一篇已解析论文的请求，不重复检索或全文获取。最终合成可以对配置的 TRANSPORT 和 TIMEOUT 故障执行有界指数退避重试。第一次输出达到上限后改用一次精简恢复请求：保留批准的 Brief、论文身份和已核验摘录，移除重复的版本、定位与证据卡结构；第二次仍达到上限则以合成专用原因停止。每次重试复用已准入证据，不重复检索、全文获取或证据抽取。共用传输逻辑在每次发送前持久化并回读准确请求，结束后记录原始输出、用量和结果。独立的 academic/synthesis-request 与 academic/synthesis-result 事件使输入 Brief 版本、证据关系、RetrievalRun 身份和尝试历史可重建。取消会中断重试等待，记录失败中止整轮，重试耗尽后保留上游成果。不使用抽取式模板回退掩盖分析失败。

模型提出中文段落和有序的问题/章节结构。一份响应最多准入十二段，每个问题最多引用两段，每段最多引用三项代表性证据；提示要求直接输出最终 JSON，并在问题与章节之间复用段落。无效 JSON、Brief 不符、段落超限及无效结构拒绝整份响应。各段落独立检查字段、证据引用超限、未知证据、仅背景引用、独立论文支持不足及反证缺少不确定性说明；主机生成拒绝记录，保留原始序号和原因。合格段落保持证据关系不变并重新编号，受影响的问题覆盖降级，空缺章节说明不足。全部段落被拒时不生成报告。只有至少两篇独立论文支持的综合才创建 Claim，单篇解释仍是来源陈述。本轮缺口写入局限或缺失原因，不作为无支持的 Claim。被拒内容不计入正文，也不代表语义审核通过。

报告显示问题覆盖、引用实际记录，并披露问题、章节与正文长度不足。同一段落重复出现时指向首次展开的位置，引用和附录不抵扣正文字数。结构有效和模型给出的 answered 标签均不证明语义支持。独立逐题审核实现前，洞察报告仅作为草稿。

## 考虑过的替代方案

**直接让模型返回 Markdown。** 难以可靠检查问题覆盖和证据引用；结构化输出便于明确校验并由主机渲染引用。

**先替换全文获取。** 现有解析器与定位对象已提供所需材料，传输失败继续独立展示。

**用模型记忆或重复引文补齐缺口。** 会掩盖证据不足，也不满足批准的研究意图。部分草稿应明确披露缺口。

## 后果

[基线决策](2026-09-14-academic-report-slice.zh.md)继续约束抽取式函数库与独立审核原则。[交接](../../../../z-team_docs/模块分工/academic-synthesis-handoff.md)、解析测试和无密钥 academic-evidence 会话场景验证混合段落恢复、报告内容保留、拒绝诊断与两个 SDK 的投影。整份响应语义修复、精简尝试后的继续恢复以及独立语义审核仍需另行推进；合成测试不证明真实论文质量。
