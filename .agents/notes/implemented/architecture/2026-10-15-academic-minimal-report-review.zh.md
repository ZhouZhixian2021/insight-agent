# Agent Note: 最小证据报告与简洁学术审批

Status: implemented

[English](2026-10-15-academic-minimal-report-review.md) | 中文

独立审核作为强制交付前置条件的决定由[自动交付](2026-10-26-academic-automatic-delivery.zh.md)取代，其余证据和分析决定仍有效。

## Problem

最小抽取保留已核验证据时，六分区卡片可以为空。仅按卡片条目准备输入会丢弃这些证据，阻止生成有限草稿。学术审批也需要自然语言反馈入口，而不把机器字段变成用户必须编辑的内容。

## Decision

准备过程对未分配给卡片条目的独立证据执行既有版本、定位、等级和哈希检查，保留空卡片和原始记录，不生成卡片字段。合成继续要求摘录和哈希，遵守批准的不足策略及零证据停止规则。缺失分区归并为一条可读限制，不重复输出内部诊断。

分析本地可选问题关联保留生产方证据 ID 和准确的批准问题文本。某段没有本题关联的支持证据时，解析过程移除对应回答中的段落引用，降低回答状态并披露缺口。未提供关联时保留原有结构处理；报告明确显示抽取覆盖不可用。关联不证明语义支持。工作流集成负责人需将生产方问题关联转发给分析及报告；本次不新增 Model、Remote、Controller 或 Workflow 字段。

学术审批分隔六个简洁决策标签而不删除原文。修改使用现有纯自定义回答，不发送批准标签或改写执行 JSON。编辑期间禁用批准，发送失败保留反馈。通用计划审批保留既有展示。

## Alternatives considered

构造完整卡片条目会掩盖抽取深度；要求所有分区完成再出草稿会保留原有阻塞。客户端解析执行 JSON 会重复 Controller 职责，也不能证明与可读正文语义一致。增加模型审核器需要独立编排、成本及 Session 记录。

## Consequences

报告分别展示批准问题、模型回答提案、正文引用的生产方关联和待内容审核状态。零引用证据不能生成合成报告；覆盖不足保留有限草稿。既有评测继续保护正式交付和独立论文数量。增强抽取、独立语义审核及真实模型计划重生成仍属于集成和联合验收，不因结构测试通过而视为完成。

## Verification

模块测试覆盖空白和部分卡片、无效记录、不足策略、缺失和错配问题关联、自然语言修改及报告交付。固定报告输出和 SDK 录制场景固定可见文字。浏览器场景使用真实问题服务及固定原计划与修订计划，不声称已验证真实模型重生成或完整学术检索。
