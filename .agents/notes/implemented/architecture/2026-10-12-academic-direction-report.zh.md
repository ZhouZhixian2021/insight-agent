# Agent Note: 正式报告遵循预设的方向层级

Status: implemented

[English](2026-10-12-academic-direction-report.md) | 中文

## 问题

预设的 report-format 描述方向级洞察，但辅助综合使用另一套提示，报告按问题排布。规划阶段加载 Skill 不会把指令传入后续模型请求，章节名称也不能提供方向结构或完整书目信息。

## 决策

分析包保留预设规范的逐字投影，由模块测试检查漂移。方向布局草稿采用下述解析与渲染；新综合请求选择[证据叙述写法](../feature/2026-10-28-academic-evidence-narrative.zh.md)。现有模型调用提出有界方向组件，引用已经有证据的陈述。标签组织批准的问题，不能包含独立的无引用结论。各组件使用索引或明确的缺少证据原因。主题最多四个，少于两个须解释限制；定量组件必须有全文支持记录。被拒段落同时失去方向关联及主题。

报告在方向地图之前展示范围、日期窗口、报告日期、来源／版本政策和执行洞察。每个方向包含主题、引用的代表论文、机制、结果、判断和面向读者的应用含义；缺少组件汇总为方法覆盖限制。跨方向综合和最终逐题回答复用原段落，引用版本与实际证据版本分别展示，日期保留来源精度，缺项明确说明，参考文献附稳定标识符或安全来源链接。数值表保留各项条件；没有可核验图示时披露限制，不补造图片。

可选方向字段属于 analysis 输出，既有输入、共享论文／Claim 类型、Remote 字段及模型传输保持不变。旧问题式草稿继续可读，同时明确指出格式不完整。方向报告仍需独立审核，不因符合布局就成为最终交付。

## 考虑过的替代方案

**运行时按仓库路径读取预设文件。** 不采用，安装后的分析包和 Web Bundle 不拥有该路径。包内投影适用于两种环境，漂移测试要求预设变更时重新审查。

**仅在逐题回答外套方向标题。** 不采用，无法确定一个方向的主题、机制和覆盖限制。

**另生成自由文本报告或填满空缺组件。** 不采用，会增加模型阶段或无追溯文字。使用现有陈述和缺少证据原因组成布局。

## 结果

A、B 保持现有材料和执行接口。结构解析继续支持旧输出，但不认证标签、数值声明或应用含义的语义，仍需可信内容审核。规范和结构会增加提示及输出长度，不改变负责人配置的预算。模块测试及现有 SDK 快照固定新旧输出路径，不运行真实来源冒烟。
