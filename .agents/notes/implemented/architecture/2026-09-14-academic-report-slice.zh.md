# Agent Note: 明确语义审核的证据到报告基线

Status: implemented

[English](2026-09-14-academic-report-slice.md) | 中文

## Problem

共享 Claim 类型既不定义分析行为，也不证明语义支持。固定证据消费方需要一条从可追溯记录到可检查报告的运行路径，同时不虚构模型适配、检索工作流或审批历史。

## Decision

[分析库](../../../../packages/academic/analysis/README.zh.md)从至少两项独立研究生成注明归属的方法与发现对比。它选择有效的正式引用版本或唯一可用版本，拒绝在多个候选版本中任意选择，并使用 A5 记录与不可变证据快照。[评测库](../../../../packages/academic/eval/README.zh.md)检查当前身份、引用、证据深度、覆盖度和明确的审核记录；仅引用完整仍保留待语义审核状态。

[报告库](../../../../packages/academic/report/README.zh.md)在自身交付入口执行评测，披露草稿限制并拒绝不安全的最终交付。[查看器](../../../../packages/client/ui-academic-research/README.zh.md)生成自包含 HTML，提供内容转义、证据导航和 Markdown 下载。独立渲染器不拥有 Session 事件；后续增加的固定数据 Web 入口见[运行页面决策](2026-09-17-academic-run-viewer.zh.md)。输入准备决策继续有效，本决策是补充而非替代。

## Alternatives considered

**从小型夹具推断广泛共识和研究空白。** 这会把样例覆盖误当领域覆盖。基线仅形成注明来源的陈述，不排名性能。

**把引用正常视为语义批准。** 记录存在不证明逻辑支持。最终交付要求另外提供针对同一证据的审核，草稿披露审核待办。

**没有工作流事件却模拟实时研究进度。** 这种进度暗示实际不存在的执行与恢复行为。查看器只呈现已生成的报告数据及质量状态。

## Consequences

本地闭环不需要网络或模型凭据，但不能替代完整学术分析、可信审核服务、Session 恢复或工作流集成。调用方须如实声明合成数据并保证审核来源可信。固定基准为虚构内容，不能作为最终成果发布。

## Testing

模块内的流程测试运行真实分析、评测和报告代码。查看器测试使用记录的流程输出，在 jsdom 中执行筛选、证据展开和下载，验证下载内容与生成的 Markdown 一致。这些测试与 HTML 文档均不宣称完成了实时 Session 集成测试。
