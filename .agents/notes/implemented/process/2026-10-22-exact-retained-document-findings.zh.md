# Agent Note: 精确保留文档检查命中

Status: implemented

[English](2026-10-22-exact-retained-document-findings.md) | 中文

## 问题

学术集成保留历史提交身份、冻结验收输入、依赖锁定以及模型或用户文本。为满足当前文档规则而重写这些记录，会改变被核对的证据或行为。排除其所在目录又会放过新增违规。

## 决策

仓库引用和具体术语检查命令把完整的原始扫描结果与[显式登记表](../../../../scripts/retained-document-findings.json)核对。每条记录指定一个文件、检查器、保留原因、命中类别、当前行及相邻行的 SHA-256 和准确出现次数。历史记录、依赖锁定和冻结样本还锁定完整文件文本，统一使用 LF 换行。检出时的换行差异不改变这些指纹；独立验收材料哈希继续承担字节级核验。

只接受精确登记的命中。新增路径、新增上下文、次数变化、锁定文件变化、文件缺失、重复登记、无效记录和未使用的登记都会使命令失败。即使原始扫描已无命中，登记错误仍然失败。原始扫描 API 保留原有结果；两个命令均不缩小发现范围，也不跳过已登记目录。某次检出缺少已登记提交的 Git 对象时，仓库引用命令仍会在锁定的文件和当前行上下文哈希均匹配后识别该提交前缀；未登记前缀仍须匹配本地对象。消除命中时，必须在同一份经过审查的改动中删除失效登记。登记表没有刷新命令。

本决策针对精确保留项，部分取代[术语禁令](2026-08-26-ban-ambiguous-origin-label.zh.md)及仓库引用检查对历史身份的无条件拒绝。两项规则仍适用于每一处未登记命中。已登记的可见文本、冻结字段消费者和模型指令仍属于行为，修改前需要另行审查；登记通过证明其保持不变，不证明运行兼容性或报告质量。

## 曾考虑的替代方案

**重写全部保留内容。** 不予采纳：历史身份和冻结输入必须保留原意，模型或用户文本也不属于本次维护范围。

**不再扫描整个目录或文件。** 不予采纳：后续违规会未经审查直接通过。完整原始扫描和精确上下文次数会继续发现已登记文件中的新增项。

**自动刷新基线。** 不予采纳：重新运行维护命令可能使改变后的证据或行为直接被接受。登记表修改必须有明确、可审查的差异。

## 后果

文档命令可以在明确登记的命中保持不变时通过。通过意味着没有未登记命中或无效登记，不再意味着原始扫描没有匹配项。锁定历史文件中的无关修改也会失败，需要专门审查。未锁定整文件的源码允许命中行移动，但其相邻行和出现次数必须完全一致。

[专项测试](../../../../scripts/retained-document-findings.spec.ts)覆盖有效登记与无效变更，并在隔离临时仓库中执行两个命令入口。测试不启动产品，也不回放研究会话。
