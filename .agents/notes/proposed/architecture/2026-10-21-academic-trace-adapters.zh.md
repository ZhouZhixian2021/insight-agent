# Agent Note: 学术 Trace 适配器

Status: proposed

[English](2026-10-21-academic-trace-adapters.md) | 中文

## Problem

学术诊断需要在两条基座升级路线间关联研究、论文和调用尝试。已有 Session 观测缺少部分运行关联与独立执行计时；直接依赖原始事件的界面需要按路线重写，也可能制造历史事实。

## Proposal

将 [C-T0 交接](../../../../z-team_docs/模块分工/academic-trace-v1-interface-handoff.md)与合成夹具作为可审核提案。各版本适配器产生共享投影，查询与展示消费投影。A/B 核对新版观察点后，C 再实现现有基座采集。缺失身份或计时保持未知。默认查询与导出只包含允许的诊断摘要，不包含模型消息或原始错误。

## Alternatives considered

在界面解析 Session JSONL 会让展示依赖持久化代际并暴露原始内容。按论文标题或相邻时间戳推断调用会合并无关操作。把完整请求复制到第二份存储会重复保存敏感数据，却无法恢复缺失身份。这些方式不纳入提案。

## Acceptance criteria

夹具校验必须在重试成功后保留首次失败，拒绝内容冲突的重复事件，保留取消与中断观测，并避免相加并发耗时。A/B 必须记录支持与缺失的观察点映射。运行时验收还需要查询权限隔离、持久化回放、稳定分页与脱敏检查；夹具校验本身不满足这些要求。

## Risks

历史证据抽取与候选审核事件不总能归属到某一次研究。可能需要新增观察身份，并单独审核持久化方式。本提案不改变现有 [Session 谱系与事件追踪](../../implemented/feature/2026-07-13-session-query-tracing.zh.md)，其解决不同的关系查询，继续有效。
